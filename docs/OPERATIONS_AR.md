# تشغيل AI HUB 2.0 والتقارير والتكلفة

## من الطلب إلى التقرير

يختار الزائر مساعدًا ويعدل الموضوع. تُحفظ المهمة ونافذة البحث عند الطلب، ثم ينفذها عامل خلفي بعد حجز الحصة والميزانية. المراحل **البحث → فحص المصادر → التحليل → إعداد PDF → جاهز** تعكس العمل الفعلي، دون تقدم وهمي أو تدفق نص مصطنع.

الواجهة الجديدة `/` والإدارة المحمية `/admin`. آخر نسخة ناجحة تبقى أثناء التحديث. النسخ وPDF ثابتة بمعرّفاتها؛ فتح نسخة سابقة لا يعيد البحث. المحادثة تستخدم التقرير المحدد، ويمكن للسؤال الذي يحتاج معلومات أحدث إنشاء مهمة بحث جديدة معلنة.

## التحقق من الأخبار

`app/research.py` مسار مشترك مع تخصصات `app/agent_profiles.py`. لكل مجال نطاق ومصادر أولية ومعايير صلة وأقسام تحليل، ولا يختلف العنوان وحده.

تُجمّد نافذة **12 ساعة** في UTC عند إنشاء المهمة، مع عرض توقيت دبي. رابط أو تاريخ يقترحه النموذج لا يثبت وقت نشر. يفحص الخادم صفحة ناشر ظهرت في مخرجات OpenAI الأصلية، ويستخرج `datePublished` أو `article:published_time` أو عنصر نشر واضحًا داخل المقال. يلزم وقت كامل بمنطقة زمنية؛ تُرفض الأوقات المستقبلية والخارجة عن النافذة والتواريخ المتعارضة. `dateModified` والزحف والتاريخ وحده غير كافية.

التغطية الحية خبر واحد عند وجود إدخال جديد بوقت نشر مثبت. النسخ المتطابقة أو المتشابهة من المادة المشتركة تُجمع ولا تُعد تأكيدات مستقلة. الحد **20 بعد التحقق والصلة وإزالة التكرار**. لا قائمة ناشرين ثابتة، ولا إكمال بأخبار قديمة.

التوقيت لا يثبت صحة كل تصريح؛ يميز التقرير المنقول والتقدير والسيناريو. فشل فحص الصفحة أو غياب التوقيت قد يقلل العدد. تحفظ diagnostics الإجمالية أسباب الاستبعاد؛ الملاحظات الخام وبيانات الاستخدام خاصة.

التاريخ يستخدم مراجع أقدم موسومة بخلفية، والإبداع مراجع إلهام موسومة. إذا غابت مراجع قابلة للفحص يستطيع Moodboard تقديم مادة قصصية أصلية صريحة بقائمة مراجع فارغة، دون ادعاء حقائق أو صور جُلبت أو وُلدت.

## حدود الطلبات

| البند | حد المسار الافتراضي |
|---|---|
| طلبات النموذج | اكتشاف واحد ثم صياغة بلا أدوات عند الحاجة |
| أفعال البحث | حتى 6 أفعال: بحث أو فتح أو عثور داخل الصفحة |
| حجز رسوم البحث | حتى 6 عمليات بحث؛ يسجل العدد الفعلي عند اكتمال الاستخدام |
| خرج الاكتشاف / الصياغة | 8192 / 8192 token |
| حمولة الاكتشاف / الصياغة | 40000 / 100000 byte قبل إرسالها |
| صفحات الناشرين | حتى 40، بحجم 1 MB للصفحة و3 تحويلات وفحص HTTPS/IP |
| التوازي | عاملان للتقارير داخل Uvicorn واحد؛ 4 فحوص صفحات داخل التقرير |
| حصة التقارير | حتى 50 محاولة يوميًا بتوقيت دبي |

هذه الحدود مستقلة عن سقف 20 خبرًا. لا وظائف منفصلة لكل ناشر ولا إعادة مدفوعة تلقائية. النموذج الافتراضي `gpt-6.1-sol` له تسعير معروف؛ تغيير النموذج يحتاج ربطًا صريحًا بأسعاره، ويخفض المسار أفعاله إلى واحد عند غياب تعريف موثوق لمضاعفات سياقه الطويل.

## الميزانية المستهدفة عند نشر 2.0

`DAILY_BUDGET_USD=900` و`MONTHLY_BUDGET_USD=28000` و`MAX_REPORTS_PER_DAY=50`. هذه **سقوف حماية محافظة وليست فواتير متوقعة**. ميزانية الدولار تشمل التقارير والمحادثة؛ رسائل المحادثة لا تستهلك حصة التقارير، لكن بحثًا جديدًا من المحادثة يُعد تقريرًا.

يُحجز المبلغ قبل أي استدعاء مدفوع. يقدّر الاكتشاف إعادة قراءة السياق المتراكم عبر الأفعال، ويستخدم معدلات محافظة للسياق الطويل وكتابة cache. سقف الحجز عند حدود الحمولات الافتراضية **16.076720 دولارًا** للتقرير؛ ثمانية اختبارات تحتاج حتى **128.613760 دولارًا** من الهامش، وخمسون محاولة حتى **803.836 دولارًا** قبل المحادثة. الاستخدام الفعلي قد يكون أقل، ولا يُفترض ذلك لتمرير طلب غير مغطى.

عند اكتمال بيانات token لكل مرحلة وعدد البحث وطبقة الخدمة والحدود يُسوّى الحجز إلى تقدير الاستخدام الفعلي. عند الغياب أو الانقطاع يبقى كامل الحجز، ولا تُختلق تكلفة صفرية. سجل التطبيق تقديري؛ فاتورة المزود مرجع التسوية النهائي. [أسعار النموذج](https://developers.openai.com/api/docs/models/gpt-6.1-sol) و[أداة البحث](https://developers.openai.com/api/docs/guides/tools-web-search).

محاضر الاجتماعات وواتساب والترجمة لا تبحث الويب. موضوعها الافتراضي بلا مادة ينتج قالبًا محليًا بتكلفة صفر؛ النص المقدم يُعالج بصياغة بلا أدوات. لا ترسل مسودات إلى أي مستلم.

## التخزين وPDF

`AI_HUB_DATABASE_PATH=/var/data/ai-hub/ai-hub.sqlite3`. المهام والنسخ والمحادثات تستخدم قاعدة البيانات الحالية بجداول إضافية؛ PDF في `reports/` بجانبها. التقرير ذو `schema_version=2` مصدر الواجهة والمحادثة وPDF نفسه.

إذا نجح التقرير وفشل PDF، يبقى قابلًا للقراءة. استخدم `POST /v1/public/workspace/reports/{id}/pdf/retry` لإعادة الإخراج المحلي دون بحث جديد. لا تولّد تقريرًا مدفوعًا لحل مشكلة خط أو PDF.

خطوط Noto الأصلية مرفقة بترخيص SIL OFL 1.1 ومصادر وبصمات محفوظة. العربية تستخدم [تشكيل fpdf2/HarfBuzz](https://py-pdf.github.io/fpdf2/TextShaping.html). احتفظ بالخطوط والترخيص مع المصدر.

## API التشغيلي

بعد `GET /v1/public/bootstrap`:

| المسار | الاستخدام |
|---|---|
| `POST /v1/public/workspace/agents/{id}/reports` | `{topic,language}` مع `Idempotency-Key`؛ مهمة `202` |
| `GET /v1/public/workspace/jobs/{id}` | الحالة والمرحلة أو التقرير المحفوظ |
| `GET /v1/public/workspace/reports?agent_id=...` | نسخ الجلسة فقط |
| `GET /v1/public/workspace/reports/{id}` | التقرير دون إعادة بحث |
| `GET /v1/public/workspace/reports/{id}/pdf` | PDF الجاهز |
| `POST /v1/public/workspace/chat/conversations/{id}/messages` | سؤال مرتبط بالمساعد والتقرير |

عند غموض الاستجابة افحص المهمة أو أعد الطلب بالمفتاح نفسه، دون إنشاء مفتاح جديد تلقائيًا. إعادة تحميل الصفحة لا تنهي مهمة الخادم. التقرير والمحادثة وPDF محكومة بملكية الجلسة، دون جسر إلى الإدارة.

## تشخيص مختصر

| الحالة | التصرف |
|---|---|
| صفر أخبار | راجع النافذة وأسباب الرفض؛ لا تعتبره إثباتًا لعدم وقوع أحداث |
| `runtime_not_configured` | يراجع المالك إعداد OpenAI في الخادم |
| `invalid_research_report` | أخفق عقد الأدلة أو الصياغة؛ لا تُعرض مخرجات غير موثقة |
| `openai_timeout` أو انقطاع عامل | افحص المهمة؛ لا تعد الطلب المدفوع تلقائيًا |
| حصة أو ميزانية `429` | راجع الحد والهامش المتاح للحجز، لا عدد الأخبار فقط |
| `pdf_failed` | احتفظ بالتقرير وأعد PDF محليًا |
| `404` لتقرير جلسة أخرى | حد ملكية مقصود؛ لا توسّع الوصول لإصلاحه |
| فقد ملفات بعد نشر | تحقق من القرص الدائم وSQLite وPDF |

الجدولة القديمة متوقفة افتراضيًا، وNewsData وAPI 1.x للتوافق السابق فقط. أوامر smoke القديمة لا تختبر مساحة 2.0. احتفظ بمعرّف المهمة والخطأ الآمن والوقت؛ لا تنسخ أسرارًا أو جسم استجابة مزود إلى الدعم. [النشر](DEPLOYMENT_AR.md) و[سجل التحقق](VALIDATION_AR.md).
