# AI HUB 1.5.1 — التشغيل والتقارير والمحادثة والاستهلاك

هذا الدليل يصف مصدر **1.5.1**. ترتبط نتائج الاختبارات والنشر بالـcommit الفعلي في [سجل التحقق](VALIDATION_AR.md) و[Actions](https://github.com/aihub1971-code/AIHUB/actions). نُشر 1.5.0 واختُبر حيًا بصفحتين و20 مقالًا مميزًا من 19 ناشرًا وترجمة عربية كاملة؛ تُسجل فحوص حد 20 والواجهة العامة في 1.5.1 بصورة منفصلة.

## 1. الإعداد

أخبار حرب إيران تستخدم NewsData.io. الترجمة العربية وبقية المساعدين والمحادثة تستخدم OpenAI. يضع المالك المفاتيح في `.env` محلي خاص أو **Environment** لخدمة Render؛ بيانات دخول الواجهة مستقلة. لا يحتاج CI إلى مفاتيح إنتاج.

| المتغير | القيمة الافتراضية أو الغرض |
|---|---|
| `APP_USERNAME` / `APP_PASSWORD` | اسم دخول المالك وكلمة مرور عشوائية طويلة |
| `NEWSDATA_API_KEY` | جلب أخبار حرب إيران؛ يرسل في رأس `X-ACCESS-KEY` من الخادم |
| `NEWSDATA_PLAN` | `unknown`؛ وصف الخطة المعروفة عند الإعداد، وليس ترقية للاشتراك |
| `NEWSDATA_PAGE_SIZE` | `10`؛ إعداد ضمن 1–50، والفعلي حتى المتبقي من سقف 20؛ المجاني حتى 10 |
| `NEWSDATA_DAILY_CREDIT_LIMIT` | `200`؛ عدد صحيح غير سالب، وحدة رصيد وليست دولارًا |
| `OPENAI_API_KEY` | الترجمة العربية وبقية المساعدين والمحادثة |
| `OPENAI_MODEL_NAME` | `gpt-6.1-sol` |
| `OPENAI_REASONING_EFFORT` | `low` |
| `MAX_OUTPUT_TOKENS` | `4096` لكل طلب صياغة أو ترجمة أو محادثة؛ ضمن 128–8192 |
| `OPENAI_RESEARCH_MAX_OUTPUT_TOKENS` | `4096` لبحث المساعدين الآخرين؛ ضمن 512–8192 |
| `AI_HUB_DATABASE_PATH` | SQLite؛ في Render تحت `/var/data/ai-hub` |
| `MAX_REPORTS_PER_DAY` | `50` محاولة تقرير كحد أقصى |
| `DAILY_BUDGET_USD` / `MONTHLY_BUDGET_USD` | `5` / `100` لتكلفة OpenAI المشتركة |
| `SCHEDULER_ENABLED` | `false` حتى اعتماد المواعيد |
| `ENABLE_API_DOCS` | `false`؛ يفضل التفعيل محليًا فقط |

يعرض `/v1/system` حالة التهيئة دون طلب مزود. وجود المفتاح لا يثبت صلاحيته أو اشتراكه. `/health` يفحص استجابة الخدمة فقط.

## 2. الواجهة العامة والإدارة واللغة

الواجهة العامة عند `/` متاحة دون تسجيل دخول، وتضم 13 مساعدًا والمحادثة بالعربية والإنجليزية؛ يرسل Enter البحث. لا تعرض التكاليف أو السجلات الإدارية. تبقى لوحة المالك عند `/admin`، وتبقى مسارات `/v1/*` الإدارية خلف مصادقة المالك، باستثناء المسارات العامة المستقلة تحت `/v1/public/*`. لا يتطلب هذا الفصل مفاتيح أو إعدادات خدمة جديدة.

تقارير الزائر ومحادثاته مرتبطة بجلسة متصفحه ولا تفتح أرشيف المالك أو جلسة أخرى. تعيد مسارات `/v1/public/*` البيانات المسموح بها دون محاسبة أو مفاتيح أو مؤشرات مزود. الأرقام والفحوص المالية في هذا الدليل تخص إدارة الخدمة؛ يبقى سجل الاستخدام والتكاليف في لوحة المالك وAPI المصادق عليه.

يغيّر زرا **العربية / English** أعلى الصفحة لغة الواجهة واتجاهها. لصفحات أخبار NewsData تُحفظ النسختان مسبقًا، ويعرض التبديل النسخة المتاحة دون طلب OpenAI. بقية التقارير المحفوظة تحتفظ بلغتها الأصلية، والتقارير الجديدة والجداول تستخدم اللغة المختارة.

لأخبار إيران، اختر **أخبار حرب إيران** وشغّل الصفحة الأولى. البحث والفترة ثابتان لهذا المساعد: `iran war` ونافذة آخر 48 ساعة. كتابة تاريخ أو موضوع مختلف في المهمة لا تغيرهما. استخدم **التالي** لجلب صفحة إضافية و**السابق** لقراءة صفحة محفوظة؛ تظهر حدود الخطة ونطاق التغطية الفعلي.

افتح المحادثة للمساعدة في استخدام المنصة أو فهم تقرير تختاره وتُرفقه صراحة. تتلقى المحادثة سياقًا محدودًا من الرسائل المكتملة والتقرير المختار، ولا تحصل على الأرشيف كله. لا تُجري المحادثة بحثًا حيًا ولا تغير الإعدادات أو الجداول بنفسها.

كل رسالة مقبولة تستخدم طلب OpenAI Responses واحدًا بلا أدوات. حد الرسالة 8000 حرف والعنوان 120؛ سياق النموذج حتى 20 دورًا مكتملًا ضمن 100000 بايت، والتقرير المختار ضمن 30000 بايت، والطلب الكامل ضمن 200000 بايت. تبقى الرسائل الأقدم محفوظة عند استبعادها من سياق النموذج. تظهر حالة انتظار فعلية دون محاكاة بث النص. [دليل المحادثة](CHAT_AND_LANGUAGES.md).

## 3. البحث والمصادر المعتمدة

### أخبار حرب إيران عبر NewsData

المسار ثابت في الخادم، وتُقرأ كل صفحة بهذا العقد:

| الحقل | القيمة |
|---|---|
| Endpoint | `GET https://newsdata.io/api/1/latest` |
| الاستعلام | `q=iran war`، مكافئ `iran AND war`؛ ليس عبارة مقتبسة تشترط تجاور الكلمتين |
| اللغة الأصلية | `language=en` |
| التكرار | `removeduplicate=1`، مع فحص الهوية والرابط داخل التطبيق |
| الوقت والترتيب | `timezone=UTC`, `sort=pubdatedesc` |
| حجم الصفحة | الأقل من `NEWSDATA_PAGE_SIZE` والمتبقي من 20؛ الافتراضي 10، مع حدود خطة المزود |
| المتابعة | مؤشر `nextPage` محفوظ داخل الخادم ويُرسل كـ`page` عند طلب التالي |

[مواصفة NewsData الرسمية](https://newsdata.io/openapi.json)، [معنى البحث](https://newsdata.io/blog/how-do-q-qintitle-qinmeta-works/) و[التصفح](https://newsdata.io/blog/newsdata-pagination/).

لا يُضاف فلتر الناشرين الستة السابق أو حصص حسب المصدر، ولا يستخدم هذا المسار بحث OpenAI أو معاملات `from_date` و`to_date` و`timeframe`. يثبت الخادم وقت الصفحة الأولى ونافذة 48 ساعة وحجم الصفحة؛ تستمر هذه القيم عند التصفح. يعرض المقال عنوانه ووصفه المتاح وناشره وتاريخ نشره ورابط المقال الأصلي. `source_url` موقع الناشر، وليس رابط المقال.

يقرأ الخادم `pubDate` مع `pubDateTZ` ويحول التاريخ للعرض. لا يستخدم `fetched_at` بديلًا للنشر ولا يستنتج تاريخ الحدث من تاريخ المقال. يفحص البيانات والوقت والرابط ويستبعد المكرر أو غير الصالح. مصدر الدليل `newsdata_structured_metadata`، و`publisher_text_verified=false`: لم يجلب التطبيق كامل نصوص الناشرين للتحقق المستقل منها.

يقتصر كل بحث على **أول 20 نتيجة يعيدها المزود قبل فحوص القبول**؛ قد يظهر عدد أقل بعد استبعاد غير الصالح أو المكرر. حجم الصفحة الافتراضي 10، ويتوقف **التالي** عند بلوغ هذا الحد أو انتهاء النتائج. **السابق** والصفحات المجلوبة سابقًا يُقرآن من التخزين دون طلب مزود جديد. `item_count` عدد الصفحة المقبول و`count_mode=provider_page`. لا يضمن حد 20 وجود 20 مقالًا صالحًا. `totalResults` إجمالي مطابقات المزود، وليس عدد النتائج المعروضة أو وعدًا بجلب جميع صفحاته.

**الخطة المجانية تؤخر المقالات 12 ساعة**، وتوفر 200 رصيد يوميًا وحد سرعة 30 رصيدًا لكل 15 دقيقة، وحتى 10 مقالات للصفحة. لا توفر كامل المحتوى أو الأرشيف. ضبط `NEWSDATA_PLAN` أو زيادة حجم الصفحة في التطبيق لا يغير هذه القيود. قد تكون نتائج اليوم المبكرة قليلة رغم عمل الاتصال. [الخطة](https://newsdata.io/blog/pricing-plan-in-newsdata-io/) و[حد السرعة](https://newsdata.io/blog/newsdata-rate-limit/).

### الترجمة المحفوظة

عند كل صفحة، يحاول OpenAI ترجمة العناوين والأوصاف الإنجليزية في دفعات حتى خمسة مقالات، **حتى لو كانت لغة الواجهة إنجليزية**. لا تتوفر أدوات أو بحث أثناء الترجمة. تُطابق النتائج بمعرّفات المقالات؛ لا تُغير الروابط والناشرين والتواريخ. الوصف الغائب يبقى غائبًا، ولا تُترجم رسالة «متاح في خطة مدفوعة» كأنها خبر.

تُحفظ `headline_en/summary_en` و`headline_ar/summary_ar` مع `response_en/response_ar`. إذا غاب مفتاح OpenAI أو تعذر إعداد الترجمة أو فشلت دفعة، تبقى المقالات الإنجليزية؛ قد تكون ترجمة الصفحة جزئية. تغيير اللغة وفتح المحفوظ لا يطلب ترجمة جديدة. لا يُدّعى أن الترجمة تحقق مستقل من الخبر.

### بقية مساعدي OpenAI

تحتفظ بقية المساعدين بوظائفها الحالية. مساعدو البحث عبر OpenAI محصورون في Financial Times (`ft.com`)، The Atlantic (`theatlantic.com`)، Politico (`politico.com`, `politico.eu`)، Wall Street Journal (`wsj.com`)، The Daily Telegraph (`telegraph.co.uk`) والجزيرة (`aljazeera.com`, `aljazeera.net`). هذه السياسة تخص مسار `web_search`، لا مسار NewsData الإيراني.

| المسار | حدود الطلبات |
|---|---|
| إيران / NewsData | صفحة مزود واحدة؛ ترجمة اختيارية لكل مجموعة من خمسة مقالات أو أقل |
| الأخبار الأخرى عبر OpenAI | اكتشاف موحد، ومتابعة اختيارية واحدة، ثم صياغة إذا توفرت أدلة؛ حتى 3 طلبات Responses |
| مساعد آخر يحتاج إلى البحث | بحث واحد ثم إجابة؛ حتى طلبين |
| مهمة بلا بحث أو رسالة محادثة | طلب نموذج واحد بلا بحث |

تحتفظ الأخبار الأخرى بحد معالجة 20 بندًا وفحوص المصدر والنشر والأدلة، دون عدد إلزامي. يظل لكل طلب بحث أصلي حد أداة واحدة. الروابط هناك مستندة إلى بيانات البحث المسموح بها، والملاحظات قراءة نموذج وليست نصوص ناشرين مستقلة التحقق. يعرض قسم المصادر بيانات التغطية عند وجودها؛ الأرشيف القديم يبقى محفوظًا كما أُنشئ. [مرجع OpenAI](https://developers.openai.com/api/docs/guides/tools-web-search).

## 4. المحاسبة وإعادة الإرسال

قبل الاتصال، تحجز معاملة SQLite واحدة حصة التقرير ورصيد NewsData وتكلفة OpenAI المحتملة. حد **50 محاولة مقبولة يوميًا بتوقيت دبي** يجمع التشغيل اليدوي والمجدول وجميع المساعدين؛ كل صفحة NewsData جديدة محاولة منفصلة، وتشمل الحصة الفشل بعد القبول. رسائل المحادثة لا تدخل فيها.

صفحة latest واحدة تحجز **رصيد NewsData واحدًا**. الحد المحلي الافتراضي 200 رصيد يوميًا، وهو منفصل عن حدود الحساب وحد السرعة لدى المزود. تُظهر `/v1/usage` الحقول `provider_credits.newsdata`، ومنها `daily_limit`, `daily_reserved`, `daily_accounted`, `daily_remaining`, `monthly_accounted` و`unit=credits`. لا تُحوّل وحدات الرصيد إلى دولار مفترض؛ اشتراك NewsData مستقل.

ميزانية OpenAI **5 دولارات يوميًا و100 دولار شهريًا** مشتركة بين التقارير والمحادثة والترجمة. تُحجز قبل جلب الصفحة جميع دفعات الترجمة المحتملة بحسب حجمها؛ عند غياب الترجمة يمكن لصفحة NewsData أن تحجز صفر دولار ورصيدًا واحدًا. تجاوز أحد الحدود يرفض العمل قبل الاتصال. لا يضمن السقف تنفيذ 50 تقريرًا يوميًا.

| تسعير OpenAI النموذجي | القيمة |
|---|---:|
| `OPENAI_PRICING_MODEL` | `gpt-6.1-sol` |
| `OPENAI_INPUT_USD_PER_MILLION` | 2 دولار لكل مليون توكن |
| `OPENAI_OUTPUT_USD_PER_MILLION` | 10 دولارات لكل مليون توكن |
| `OPENAI_WEB_SEARCH_PRICE_USD_PER_CALL` | 0.01 دولار لكل أداة بحث لدى المساعدين الآخرين |

يستخدم تقدير الإدخال معاملًا محافظًا 1.25 دون افتراض خصم التخزين المؤقت. يلزم تطابق التسعير مع اسم النموذج. هذه قيم المصدر المبنية على المراجعة السابقة؛ راجع [النموذج](https://developers.openai.com/api/docs/models/gpt-6.1-sol) و[التسعير](https://developers.openai.com/api/docs/pricing) قبل تغييرها. لا توجد رسوم `web_search` لمسار إيران؛ تكلفة OpenAI فيه للترجمة فقط.

يبقى الاحتياطي عند الفشل أو انقطاع العمل أو غموض الاستخدام، ويُراجع حين تكتمل بيانات المحاسبة. السجل تقدير التطبيق، لا فاتورة نهائية، ولا يشمل الاشتراكات أو الاستضافة أو الضرائب أو استعمال المفاتيح خارج التطبيق. تحفظ السجلات فصل الدولار عن الرصيد حتى عند فشل الترجمة بعد نجاح الأخبار.

يحمي `Idempotency-Key` الطلب من تكرار الاستهلاك. يُعاد عرض النتيجة أو الحالة للمفتاح والجسم نفسيهما؛ تغيير الجسم بالمفتاح نفسه مرفوض. يحفظ الخادم علاقة صفحات إيران، ويعيد الابن المحفوظ عند تكرار الانتقال نفسه. **السابق** قراءة محفوظة فقط. لا توجد إعادة تلقائية لطلبات مزود فاشلة، ومؤشر المزود لا يظهر في API أو التنزيل. إعادة إنشاء تقرير أول بمعرّف جديد طلب جديد.

في المحادثة يُسمح بدور معلق واحد، وتظل الرسائل الفعلية وحالاتها محفوظة. بعد أكثر من 15 دقيقة تُعلّم الأعمال العالقة بالانقطاع عند استعادة الحالة مع بقاء الاحتياطي؛ لا تُرسل تلقائيًا من جديد.

## 5. الجدولة

الأوقات ثابتة بتوقيت دبي، مثل `08:00` و`16:00`. مثال `POST /v1/schedules`:

```json
{
  "name": "أخبار حرب إيران",
  "agent_id": "iran-news",
  "task": "اعرض آخر أخبار حرب إيران مع العناوين والملخصات والروابط.",
  "language": "ar",
  "times": ["08:00", "16:00"],
  "enabled": false
}
```

لتشغيل جدول معتمد، يلزم `enabled=true` للجدول و`SCHEDULER_ENABLED=true` في البيئة ثم إعادة التشغيل. حدّث قيمة Blueprint أيضًا حتى لا تعكسها مزامنة لاحقة. الحالة الافتراضية الحالية متوقفة؛ لا يفعّل تحديث 1.5.1 الجداول تلقائيًا.

- مجموع أوقات الجداول المفعلة لا يتجاوز 50 وقتًا يوميًا؛ المحاولات اليدوية تشاركها الحصة الفعلية.
- يفحص المجدول المواعيد كل نحو 15 ثانية ويشغّل التقارير بالتتابع.
- مهلة الموعد المتأخر 5 دقائق؛ تُتجاوز المواعيد الأقدم دون دفعة تعويضية.
- الإنشاء والتعديل وإعادة التفعيل تسري على الأوقات التالية فقط.
- الموعد المحجوز لا يتكرر تلقائيًا بعد إعادة التشغيل أو الفشل.
- تستمر الخدمة بنسخة واحدة وعامل Uvicorn واحد؛ التشغيل المحلي يتوقف عند إطفاء الجهاز.

## 6. مرجع API والفحص

الواجهة العامة لها مسارات مستقلة وردود تخلو من المحاسبة؛ لا تفتح أرشيف المالك أو الجداول للزائر. كل مسارات `/v1/*` الإدارية تتطلب مصادقة HTTP Basic للمالك؛ الاستثناء هو `/v1/public/*` المخصص لجلسة الزائر. استخدم HTTPS خارج جهازك. المهام والرسائل محدودة بـ8000 حرف؛ الحقول غير المعروفة مرفوضة.

| المسار | الغرض |
|---|---|
| `GET /health` | فحص استجابة عام بلا اتصال بالمزود |
| `GET /v1/agents` و`GET /v1/system` | المساعدون وحالة التهيئة |
| `POST /v1/agents/{id}/run` | تقرير جديد بالجسم `{task, language}`؛ لإيران يمكن إضافة `continue_from_report_id` لتقرير محفوظ |
| `GET /v1/reports` و`GET /v1/reports/{id}` | الأرشيف ونتيجة التقرير |
| `GET /v1/reports/{id}/download?format=md` أو `format=json` | تنزيل محفوظ دون توليد |
| `GET /v1/usage` | حصص التقارير وتكاليف OpenAI ورصيد NewsData المستقل |
| `GET/POST /v1/chat/conversations` | قائمة المحادثات وإنشاء محادثة مجانية |
| `GET /v1/chat/conversations/{id}` | الرسائل والحالة؛ يدعم `limit` و`before` |
| `POST /v1/chat/conversations/{id}/messages` | رسالة مع `Idempotency-Key` مطلوب و`report_id` اختياري |
| `GET/POST /v1/schedules` و`PATCH/DELETE /v1/schedules/{id}` | إدارة الجداول ولغتها |
| `GET /v1/schedule-occurrences` | سجل تنفيذ المواعيد وتجاوزها |

شغّل `python -m pytest` للفحوص الاصطناعية، ثم `python scripts/smoke_test.py` لفحص الخدمة دون توليد. الخيار `--live --agent iran-news` يجلب **صفحة أخبار واحدة** برصيد NewsData واحد وترجمة OpenAI عند توفرها. يطبع السكربت معرّف الطلب قبل التنفيذ ويمكن إعادة استخدامه عبر `--request-id` لمراجعة الطلب نفسه. تشغيله بمعرّف جديد محاولة جديدة. افحص الأرشيف والبحث والتواريخ بعد الطلب؛ HTTP ناجح أو وجود مراجع كثيرة لا يعني وجود أخبار مقبولة.

## 7. الديمومة والنسخ الاحتياطي

تحفظ SQLite التقارير والمحادثات والرسائل والجداول وكلا سجلي التكلفة. أضاف تحديث 1.4.0 جداول الدردشة وعمود لغة الجداول مع افتراضي عربي دون حذف السجلات السابقة. تُحفظ بصمات طلبات التقارير العربية القديمة كما كانت. خذ نسخة متسقة قبل التحديثات التشغيلية:

```bash
python scripts/backup_database.py --output ./backups/AI_HUB_Backup_2026-10-20.sqlite3
```

السكربت يستخدم واجهة SQLite للنسخ ويفحص سلامة النسخة ويرفض الكتابة فوق ملف قائم. لا تنسخ ملف القاعدة الرئيسي وحده أثناء الكتابة لأن WAL قد يحوي بيانات حديثة. في Render يقع الملف وملفات WAL تحت `/var/data/ai-hub` على القرص نفسه. انقل النسخة إلى وجهة خاصة خارج القرص؛ وجودها على القرص نفسه لا يحمي من فقدانه. [مرجع Render للأقراص](https://render.com/docs/disks).

اختبر الاستعادة في نسخة منفصلة والمجدول متوقف، وافحص التقارير والمحادثات والحصة. لا تستبدل قاعدة إنتاج وهي مستخدمة. تُستبعد القواعد والنسخ والبيانات السرية من Git وحزمة المصدر.

## 8. التشخيص

| الحالة | الإجراء |
|---|---|
| `401` أو `auth_not_configured` | راجع بيانات دخول المالك في الخدمة |
| `runtime_not_configured` أو ربط أسعار غير صحيح | راجع المفتاح واسم النموذج والأسعار دون نسخ القيم السرية إلى الدعم |
| أخبار إيران قليلة أو صفر | راجع تأخير الخطة ونافذة 48 ساعة وعدد الصفحة وأسباب الاستبعاد؛ قد تتوفر صفحة تالية |
| `newsdata_not_configured` أو `newsdata_auth_failed` | راجع وجود مفتاح NewsData وصلاحيته داخل Environment دون عرضه |
| `newsdata_access_denied` أو `newsdata_page_size_invalid` | طابق حجم الصفحة مع الخطة؛ أبقِ المجاني عند 10 أو أقل |
| `newsdata_rate_limited` أو نفاد رصيد التطبيق | راجع رصيد NewsData وحد السرعة وحد اليوم المحلي؛ لا تعِد المحاولة تلقائيًا |
| `newsdata_page_unavailable` | راجع التقرير المحفوظ؛ قد يكون مؤشر الصفحة قد انتهت صلاحيته لدى المزود |
| الترجمة غير متاحة | يبقى النص الإنجليزي؛ راجع إعداد OpenAI وحالة الترجمة والتكلفة |
| `openai_timeout` أو `openai_api_error` | راجع المحاولة المحفوظة وكود الخطأ؛ لا تُعد الإرسال تلقائيًا بمعرّف جديد |
| `429` | راجع حصة التقارير أو الميزانية المشتركة لليوم والشهر |
| `409` لمعرّف الطلب | افحص الحالة المحفوظة قبل طلب محاولة جديدة |
| `conversation_busy` أو `chat_in_progress` | افتح المحادثة وتحقق من الدور المعلق |
| `chat_history_changed` | حدّث المحادثة؛ لم تُرسل المحاولة المتعارضة إلى OpenAI |
| `chat_report_not_found` أو `chat_report_unavailable` | اختر تقريرًا محفوظًا مكتملًا |
| فقدان السجل بعد النشر | راجع القرص ومسار SQLite وملفات WAL |
| الجدولة لا تعمل | راجع التفعيل العام وتفعيل الجدول وتوقيت دبي والميزانية |

احتفظ بالكود الآمن ومعرّف التقرير أو الدور ووقت حدوث المشكلة. لا تنسخ مفاتيح API أو كلمات المرور أو رؤوس Authorization أو جسم خطأ المزود إلى محادثة الدعم.
