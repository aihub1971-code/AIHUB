# تشغيل AI HUB 2.0.4 والتقارير والأخبار

هذه الوثيقة تصف التنفيذ الحالي. **التحقق النهائي والنشر والفحص الحي معلّقة**؛ تُضاف نتائجها الفعلية إلى [ملاحظات 2.0.4](FIXES_2_0_4.md) و[سجل التحقق](VALIDATION_AR.md). سجلات 2.0.1–2.0.3 تبقى دليلًا تاريخيًا لإصداراتها، ولا تثبت نجاح الإصلاح الجديد.

## المسارات الحالية

الواجهة العامة `/` لا تحتاج بيانات المالك، والإدارة `/admin` محمية. يوجد **تسعة مساعدين نشطين**؛ توقفت محاضر الاجتماعات وملخص واتساب والترجمة الأدبية والاستعداد للاجتماع عن الطلبات الجديدة، مع بقاء التقارير وPDF والمحادثات وملفات المصدر المؤرشفة. لا تُحذف قاعدة البيانات أو ملفات الأرشيف لتطبيق الإزالة.

سبعة مساعدين يستخدمون `app/news_feed.py` لأخبار NewsData: الدخل الأساسي، إيران، التجارة الإماراتية الأوروبية، الجغرافيا السياسية، التعليم، الاقتصاد والثقافة، ودعم القرار. يستخدم التاريخ وStory Moodboard البحث الأصلي المقيد ومراجع قديمة موسومة. سجل المساعدين والصلاحيات هو مرجع تفعيل الطلبات؛ وجود ملف مهارة مؤرشف لا يفعّله.

## من لوحة الأخبار إلى التقرير

عند فتح لوحة الأخبار يعيد GET المخزن الحالي سريعًا، ويبدأ تحديثًا خلفيًا إذا حل موعده. يطلب التحديث اليدوي العملية نفسها دون تجاوز الحجز أو الرصيد أو التهدئة. يتشارك الزوار نسخة أخبار المجال، وتستخدم الخدمة استعلامات ثابتة يملكها الخادم؛ لا تصبح مواضيع التقارير الخاصة محتوى عامًا في المخزن.

تعرض الواجهة حالات **محدّثة، محفوظة، جارٍ التحديث، فارغة، وخطأ مزود**، مع آخر نجاح وموعد التحديث التالي والعدد الفعلي ووقت النشر والمصدر. يبقى محتوى صالح من النسخة السابقة ظاهرًا أثناء التعثر. نجاح استدعاء بلا أخبار مؤهلة حالة فارغة صريحة؛ فشل المصدر لا يتحول إلى نجاح فارغ. تُستبعد الأخبار التي تجاوز عمرها 12 ساعة من العرض الحي.

اختيار بطاقة مساعد يبدأ تقريرًا صريحًا بموضوع قابل للتعديل. تُجمّد نافذة التقرير، ثم يحجز العامل الحصة والميزانية ويستخدم المصدر المناسب. مراحل **البحث ← فحص المصادر ← التحليل ← الحفظ ← إعداد PDF ← جاهز** تصف العمل الفعلي؛ يمكن لمسار المراجع الأصلي العودة من فحص المصادر إلى بحث إضافي داخل حدوده. لا تقدم وهمي أو بث نص مصطنع.

يبقى التقرير السابق ووقته محفوظين. تستعيد إعادة التحميل آخر مهمة وسبب فشلها ومرجعها ومرحلتها، وتتيح إعادة محاولة صريحة إذا سمح نوع الخطأ والمهلة. قراءة الأخبار أو تحديثها أو تغيير لغتها لا ينشئ تقريرًا ولا يطلق نموذجًا. المحادثة التي تطلب أدلة أحدث قد تنشئ تقريرًا جديدًا عبر البوابة نفسها.

## نافذة الأخبار ومستوى الأدلة

النافذة **12 ساعة** بتوقيت UTC في التخزين ودبي في العرض. يعتمد قبول مقالات NewsData على `pubDate` و`pubDateTZ` المنظمين، مع رفض الوقت الناقص أو الملتبس أو المستقبلي أو الخارج عن النافذة، وفحص الصلة والروابط وإزالة التكرار قبل سقف **100 مقال**.

المستوى `provider_metadata_only` و`publisher_text_verified=false`: تم فحص بيانات المزود، ولا يثبت ذلك قراءة نص صفحة الناشر أو التحقق من صحة كل ادعاء. روابط المصادر والتواريخ والمعرفات تُعين من بيانات الخادم؛ لا يخترعها نموذج التحليل. لا تُملأ القائمة بقديم أو بمعرفة النموذج للوصول إلى 100.

في فحص حي تشخيصي لإيران بتاريخ **20 أكتوبر 2026، 18:11:09 UTC** كان أحدث وقت نشر في الصفحة **06:10:59 UTC**. كانت المقالات العشرة المعادة خارج 12 ساعة، فكان عددها المؤهل صفرًا. رفض المزود حجم الصفحة 50 وحدد النطاق 1–10. `NEWSDATA_PLAN` غير معروف؛ لا تثبت هذه الملاحظات أن الخطة مجانية. يُعرض تأخر محتمل في الوصول الحالي مع أحدث وقت نشر، وقد يلزم وصول آني يفي بالنافذة. هذه الملاحظة سابقة لإثبات نجاح الإصدار الجديد.

## حدود NewsData

| البند | الحد أو السياسة |
|---|---|
| الأخبار المقبولة | حتى 100 بعد التوقيت والصلة وإزالة التكرار |
| الصفحات | حتى 20، مع توقف مبكر عند استنفاد النافذة أو النتائج أو العدد |
| مدة التحديث | حتى 90 ثانية |
| النتائج الخام | حتى 1000 ضمن سقف الصفحات وحجمها |
| حجم الصفحة | حتى 10 عند `unknown` أو `free`؛ حتى 50 عند `paid`، مع احترام `NEWSDATA_PAGE_SIZE` |
| فاصل المخزن |15 دقيقة للمجال، مشترك بين الجلسات |
| التوازي | تحديث واحد للمزود في الوقت نفسه، بحجز ومدة صلاحية |
| التهدئة | مشتركة بين المجالات عند تقييد المزود أو أخطاء الوصول/الاتصال؛ لا يتجاوزها التحديث اليدوي |
| الرصيد | `NEWSDATA_DAILY_CREDIT_LIMIT=200` قائم، مشترك مع استخدام المحول السابق |
| احتساب الطلب | رصيد واحد محجوز قبل كل صفحة؛ لا تصفير عند إعادة التحميل أو النشر |
| عند فشل تحديث | احتفاظ بالمحتوى السابق المفيد ووقت نجاحه، مع خطأ آمن وحالة قديمة/جزئية عند انطباقها |

`NEWSDATA_PLAN=paid` ليس اختبارًا لاستحقاق الحساب ولا طريقة لتجاوز رد المصدر. لا تُغيّر الخطة أو الرصيد لإخفاء تأخر المصدر. `next_refresh_at` و`retry_after_seconds` يحددان أقرب وقت مسموح للمحاولة التالية؛ لا يحددان موعد تنفيذ تلقائي. تحديث الأخبار يدوي: لا يطلق GET جلبًا عند فراغ المخزن أو انتهاء صلاحيته، ولا يؤدي فتح الصفحة أو إبقاؤها مفتوحة أو تبديل اللغة إلى طلب NewsData. يبدأ الجلب عبر زر التحديث أو طلب تقرير/بحث حديث صريح، ولا يشغّل تحديث المخزن نموذجًا. قد تستمر الواجهة في قراءة حالة تحديث جارٍ حتى ينتهي، وهذه القراءات لا تبدأ جلبًا جديدًا. أبقِ `SCHEDULER_ENABLED=false` لمنع إنشاء تقارير مجدولة في الخلفية.

## التحليل والترجمة والبحث الأصلي

تحليل الأخبار والترجمة العربية/الإنجليزية يستخدمان طلبات **بلا أدوات** (`tools=[]`، `tool_choice=none`) ضمن خطة محدودة وحجز تقرير صريح. تبقى حدود المدخلات والمخرجات وعدد الاستدعاءات منفصلة عن عدد المقالات. تعرض النسخة `actual_article_count` و`analyzed_article_count` و`requested_article_target`؛ جمع 100 مقال لا يعني تحليل 100 بالتفصيل.

تعمل الترجمة على دفعات محدودة من النص المقدم، وتحافظ على المعرفات والمصدر والوقت. لا تجلب صفحات ولا تبحث ولا تختلق ملخصًا غير موجود. يمكن تخزين الترجمة الناتجة لإعادة استخدامها عند قراءة المخزن؛ غيابها يُظهر لغة المصدر وتنبيهًا. لا ترجمة تلقائية مدفوعة عند فتح الصفحة أو تبديل اللغة، ولا إعادة نموذج مدفوعة تلقائية عند الخطأ.

التاريخ وStory Moodboard يبقيان على مسار OpenAI الأصلي: أفعال بحث/فتح/عثور محدودة، ومخرجات وصياغة مقيدة، وفحص صفحات ناشر بحدود HTTPS وDNS والحجم والوقت. سقف المسار الافتراضي حتى 6 أفعال أصلية، و 40 صفحة ناشر، و 8192 token لخرج مرحلة الاكتشاف/الصياغة، ومدخل 40000/100000 byte. تغيير النموذج يحتاج تسعيرًا مطابقًا وخطة حدود محافظة. لا وظائف منفصلة لكل ناشر، ولا تجاوز لحماية المواقع.

تُوسم المراجع الأقدم بالتاريخ والإبداع بخلفية أو إلهام، وتُوسم الحبكة والألوان الأصلية كتفسير إبداعي. تختلف أدلتها المفحوصة عن بيانات NewsData؛ لا يُدمج الوصفان في ادعاء تحقق واحد.

## الحصص والميزانية القائمة

لا يغيّر 2.0.4 القيم: `MAX_REPORTS_PER_DAY=100`، و`DAILY_BUDGET_USD=900`، و`MONTHLY_BUDGET_USD=28000`، و`NEWSDATA_DAILY_CREDIT_LIMIT=200`. هذه سقوف حماية لا فواتير متوقعة. تبقى المحاولات الفاشلة السابقة محسوبة؛ لا تُمسح السجلات ولا تُعاد الأرصدة إلى الصفر.

المحادثة تشارك ميزانية النموذج ولا تستهلك محاولة تقرير إلا عند بدء بحث جديد. عند غياب `MAX_REPORTS_PER_DAY` تبقى القيمة الافتراضية 50. حد المواعيد النشطة 50 مستقل، و`SCHEDULER_ENABLED=false` قائم. عاملان للتقارير يعملان داخل عملية Uvicorn واحدة وعلى القرص نفسه؛ لا تضف نسخ خدمة أو عمال Uvicorn إضافيين مع SQLite الحالية.

يُحجز تقدير محافظ قبل نموذج التحليل/الترجمة أو البحث الأصلي؛ تُسوّى بيانات الاستخدام الكاملة فقط. عند نقص بيانات الاستخدام أو تجاوز الحدود أو الانقطاع يبقى الحجز، ولا تُختلق تكلفة صفرية. لا يُطبق تقدير المسار الأصلي القديم على كل تقرير أخبار جديد؛ لكل مسار خطة حجزه. فاتورة المزود مرجع المحاسبة، وسجل التطبيق حد وتقدير تشغيلي.

## التخزين وPDF

`AI_HUB_DATABASE_PATH=/var/data/ai-hub/ai-hub.sqlite3`. تُضاف جداول المخزن والمهام والنسخ والمحادثات إلى قاعدة البيانات القائمة؛ PDF في `reports/` بجانبها. تبقى ملفات WAL والنسخ الاحتياطية وPDF تحت الحماية نفسها. لا تُنشر هذه الملفات في المستودع أو حزمة المصدر.

التقرير ذو `schema_version=2` مصدر الواجهة والمحادثة وPDF. إذا حُفظ التقرير وفشل PDF، استخدم `POST /v1/public/workspace/reports/{id}/pdf/retry` لإعادة الإخراج المحلي دون بحث جديد. خطوط Noto وترخيص SIL OFL 1.1 ومصادرها وبصماتها مرفقة؛ يستخدم الإخراج تشكيل fpdf2/HarfBuzz. تُحفظ لغة التقرير ونافذته عند قراءة نسخه لاحقًا.

## API التشغيلي

بعد `GET /v1/public/bootstrap`:

| المسار | الاستخدام |
|---|---|
| `GET /v1/public/workspace/config` | المساعدون التسعة والمجالات الإخبارية السبعة واللغتان |
| `GET /v1/public/workspace/agents/{id}/news?language=ar` | قراءة المخزن وحالته فقط؛ لا يبدأ جلب أخبار |
| `POST /v1/public/workspace/agents/{id}/news/refresh` | `{language}`؛ تحديث يدوي تحت القيود نفسها |
| `POST /v1/public/workspace/agents/{id}/reports` | `{topic,language}` مع `Idempotency-Key`؛ مهمة 202 |
| `GET /v1/public/workspace/agents/{id}` | آخر تقرير ناجح والمهمة الجارية وآخر مهمة |
| `GET /v1/public/workspace/jobs/{id}` | الحالة والمرحلة والخطأ الآمن والتقرير المحفوظ |
| `GET /v1/public/workspace/reports?agent_id=...` | نسخ الجلسة فقط |
| `GET /v1/public/workspace/reports/{id}` | النسخة دون إعادة بحث |
| `GET /v1/public/workspace/reports/{id}/pdf` | PDF الجاهز |
| `POST /v1/public/workspace/chat/conversations/{id}/messages` | سؤال مرتبط بالمساعد والتقرير |

عند غموض إرسال تقرير أو رسالة افحص العملية القائمة أو أعد الجسم والمفتاح نفسيهما. لا تنشئ مفتاح محاولة مدفوعة جديدة تلقائيًا. السجل الخاص والتقرير والمحادثة وPDF محكومة بملكية الجلسة؛ المخزن العام منفصل عنها.

## التشخيص والاستعادة

| الحالة | التصرف |
|---|---|
| صفر أخبار مع `provider_delay` | راجع أحدث وقت نشر والنافذة؛ لا تضم قديمًا ولا تفترض نوع خطة غير متحقق |
| `newsdata_not_configured`/`newsdata_auth_failed` | يراجع المالك إعداد المصدر الخاص دون إظهار المفتاح |
| `newsdata_rate_limited`/`newsdata_daily_credit_limit` | احترم `next_refresh_at` والرصيد القائم؛ لا تتجاوز الحجز أو التهدئة |
| `newsdata_timeout`/`newsdata_connection_error` | اعرض خطأ المصدر والنسخة السابقة إن وجدت؛ لا تزعم نجاح تحديث فارغ |
| `invalid_report_stage` | احتفظ بمعرف المهمة والمرحلة؛ كان الانتقال من فحص المصادر إلى البحث سببًا مثبتًا في التشخيص |
| تجاوز حدود البحث الأصلي | احتفظ بعدد الأفعال والسبب الآمن؛ لا ترفع الحد أو تعِد الاستدعاء تلقائيًا |
| `openai_auth_failed`/`openai_access_denied`/`openai_request_rejected` | راجع تهيئة الخدمة؛ لا تعرض رد المزود الخام |
| `openai_quota_exceeded` | يراجع المالك إتاحة الخدمة؛ تبقى النسخ المحفوظة |
| `openai_rate_limited`/`openai_unavailable`/`openai_timeout` | اعرض المرجع والمرحلة ومهلة الانتظار وخيار إعادة صريح عندما يسمح به |
| حصة تقرير أو ميزانية 429 | راجع الحصة والهامش للحجز؛ لا تغيّر السجل ولا تعرض مبالغ في الواجهة العامة |
| `pdf_failed` | احتفظ بالتقرير وأعد PDF محليًا |
|404 لسجل جلسة أخرى | حد ملكية مقصود، وليس سببًا لتوسيع الوصول |

شمل التشخيص الفعلي `invalid_report_stage` وفشل حدود البحث الأصلي وضياع تفاصيل مزود مفيدة خلف رسالة عامة. يعالج المصدر انتقال المرحلة وحفظ الأسباب الآمنة وعرضها؛ **التحقق النهائي من النتيجة الحية لم يكتمل بعد**. لا تنسخ مفاتيح أو أجسام ردود مزود إلى الدعم. أبق السجلات التاريخية كما هي وأضف أدلة الإصدار الجديد عند اكتمالها.
