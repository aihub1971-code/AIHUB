# تشغيل AI HUB 2.1

هذه تعليمات المصدر الحالي. دليل التغيير في [UPGRADE_2_1.md](UPGRADE_2_1.md)، وأدلة الاختبارات والنشر والفحص الحي تضاف إلى [سجل التحقق](VALIDATION_AR.md). لا يُستنتج نجاح الوصول إلى المزود من رقم الإصدار أو استجابة الصحة.

## الواجهات والملكية

تعمل واجهة الزائر عند `/`، وواجهة الوكلاء للمالك عند `/admin/agents`. الواجهتان تعرضان الوكلاء السبعة أنفسهم، بمحادثة مستقلة لكل وكيل وأخبار وتقارير عند الطلب. تبقى `/admin` لوحة الصيانة والأرشيف السابقة. مصادقة المالك مطلوبة على `/v1/workspace/*`، ولا تقبل جلسة زائر بدلًا منها. ملفات PDF والمحادثات والملاحظات والتقارير الخاصة تخضع لملكية صاحبها.

فتح الوكيل أو تبديله أو تغيير اللغة أو استعادة المحادثة يقرأ البيانات المحفوظة فقط. يبدأ البحث بعد إرسال طلب يحتاج أدلة جديدة أو اختيار زر التحديث/التقرير. المخزن العام للأخبار لا يحتوي نصوص محادثات الزوار أو مهامهم الخاصة. `GET` لا يحجز تحديثًا حتى عندما يكون المخزن فارغًا أو قديمًا.

## الأخبار ومسارا الجلب

يتاح NewsData وبحث الويب لكل وكيل نشط. تستخدم الأخبار العامة موضوعات الخادم المحددة. يبحث الوكيل عن أدلة السؤال العادي على الويب ويجيب داخل المحادثة الخاصة؛ يبدأ سير التقرير وPDF عند طلب تقرير صراحةً.

| القيد | التنفيذ الحالي |
|---|---|
| نافذة الأخبار الحالية | 12 ساعة؛ التخزين بوقت محدد المنطقة والعرض بتوقيت دبي |
| سقف NewsData | 50 نتيجة خام إجمالًا قبل فحص التوقيت والصلة والتكرار |
| الأخبار المعروضة | حتى 50 مقالة مؤهلة؛ قد يقل العدد أو يكون صفرًا |
| زمن مرحلة NewsData | حتى 90 ثانية، مع توقف مبكر عند بلوغ السقف أو نهاية المصدر |
| حجم الصفحة | بحسب الخطة المهيأة وقدرة المزود؛ الإعداد لا يثبت استحقاق الحساب |
| عمر المخزن | قد تُوسم النسخة المحفوظة بالقدم بعد 900 ثانية، لكن هذا العمر لا يمنع تحديثًا يدويًا جديدًا بعد نجاح السابق؛ تبقى تهدئة المزود الحقيقية وحماية الطلب الجاري ساريتين |
| بحث ويب إضافي | استدعاء اكتشاف محدود، حتى فعلين أصليين و12 صفحة ناشر |
| حجز التحديث | 420 ثانية لاستيعاب مسار الجلب الإضافي؛ قراءات الحالة لا تبدأ جلبًا جديدًا |
| الجدولة | `SCHEDULER_ENABLED=false` للتشغيل اليدوي المقصود |

لا يستمر التصفح حتى الحصول على 50 خبرًا مقبولًا؛ النتيجة المرفوضة أو المكررة تستهلك مكانًا من سقف النتائج الخام. لا تُوسّع نافذة الأخبار ولا تُملأ بمواد قديمة. الوقت الناقص أو الملتبس أو المستقبلي لا يُقدّم كتوقيت موثوق.

قد يستدعي التحديث الصريح بحث ويب إذا كانت تغطية NewsData ناقصة أو غير متاحة. هذا المسار **قد يستهلك استخدام OpenAI وحصة محاولة من سجل التطبيق**، بحجز محافظ وحدود معلومة. لا تُفترض مجانية التحديث اليدوي، ولا تُطلق محاولات نموذج متكررة عند الفشل. تبقى بيانات NewsData الوصفية منفصلة عن النصوص والتواريخ المفحوصة في صفحات الناشرين.

## الحصص والتهدئة

إعدادات التشغيل الحالية هي `MAX_REPORTS_PER_DAY=500` و`DAILY_BUDGET_USD=900` و`MONTHLY_BUDGET_USD=28000` و`NEWSDATA_DAILY_CREDIT_LIMIT=500`. يشير `MAX_REPORTS_PER_DAY` إلى حصة البحث المشتركة في التطبيق، رغم بقاء اسمه البرمجي القديم. هذه سقوف حماية، وليست فواتير متوقعة أو إثباتًا للحصة المتاحة في حساب المزود. احتفظ بقيم الخدمة القائمة ولا تصفر السجلات عند الترقية. عند غياب متغير حصة البحث تبقى القيمة الافتراضية في التطبيق 50.

يفصل الخطأ بين `scope=application` و`scope=provider`، وبين حد رصيد التطبيق وحد رصيد المزود وحد معدل الطلبات. `newsdata_daily_credit_limit` يخص السقف المحلي؛ `newsdata_provider_credit_limit` يخص رصيد NewsData؛ و`newsdata_rate_limited` يخص التهدئة لدى المزود. حدود استخدام OpenAI المحلية منفصلة عن `openai_quota_exceeded` و`openai_rate_limited`.

بعد معالجة إعداد أو حصة محلية، يمكن للمشغّل اختيار تحديث صريح لإعادة الفحص دون انتظار نسخة الخطأ القديمة حتى منتصف الليل. السجل يعيد التحقق ويمنع عمل المزود إن بقي الحد مستنفدًا. أما تهدئة المزود فتظل ملزمة. لا يؤدي انتهاء مهلة أو تعديل إعداد إلى طلب تلقائي من الواجهة.

الحجز المحافظ يسبق العمل المدفوع، وتتم التسوية عند اكتمال بيانات استخدام صالحة. تبقى قيمة الحجز عند الغموض أو الانقطاع؛ لا تُسجل تكلفة صفرية مفترضة. تستهلك كل محاولة بحث ويب جديدة في المحادثة محاولة واحدة من حصة البحث المشتركة؛ لا يستهلك فحص الطلب نفسه بمفتاحه المحفوظ محاولة أخرى. المحادثة المحلية دون بحث ويب لا تخصم محاولة بحث، لكنها تشارك ميزانية النموذج إذا استدعته. أما طلب تقرير صراحةً من المحادثة فيستهلك محاولة تقرير ضمن الحصة المشتركة.

## التقارير والمعرفة المشتركة

التقرير نسخة ثابتة لها لغة ونافذة ومصادر وتوقيت بحث. يختلف عدد الأخبار المجموعة عن عدد الأخبار المحللة. إذا لم توجد مادة حديثة كافية لكن المراجع الخلفية مفيدة، يحافظ `background_only` على التحليل مع تنبيه وتواريخ واضحة. لا تعني هذه الحالة فشل التقرير أو منع PDF.

الخادم يستعيد محادثة واحدة لكل وكيل ولكل صاحب مساحة. يسترجع سياقًا محدودًا من محادثاته وتقاريره وملاحظاته المعتمدة. الملاحظات المقترحة أو المرفوضة لا تدخل الذاكرة المشتركة المعتمدة. الموافقة على تصحيح أو تفضيل ليست تحققًا مستقلاً من مضمونه، ولا تغييرًا لأوزان النموذج.

البث الفعلي يستخدم `status` و`delta` و`complete` و`error`. النص الجزئي لا يتحول إلى روابط قبل قبول الإجابة المكتملة. انقطاع الاتصال غير المؤكد يُفحص بالمفتاح والجسم نفسيهما؛ إعلان الخادم فشل المحاولة لا يبرر إرسال محاولة مدفوعة جديدة تلقائيًا.

## التخزين والتشغيل

استخدم قاعدة البيانات القائمة عند `/var/data/ai-hub/ai-hub.sqlite3` ومجلد `reports/` بجانبها. الجداول الجديدة إضافية، ولا تستلزم حذف الأرشيف أو سجل التكلفة. احمِ SQLite وملفات WAL والنسخ الاحتياطية وPDF بالحماية نفسها؛ لا تُدرجها في حزمة المصدر.

تعمل الخدمة بعملية Uvicorn واحدة وعاملي تقارير داخل التطبيق (`REPORT_JOB_WORKERS=2`) على القرص نفسه. لا تضاعف عمليات Uvicorn أو تنشئ نسخة خدمة بقاعدة منفصلة لإصلاح مهمة متعثرة. احتفظ بخطوط Noto وملفات ترخيصها ومصدرها؛ إخراج PDF يستخدم البيانات المحفوظة وتشكيل العربية.

إذا حُفظ التقرير وفشل PDF، أعد الإخراج عبر `/reports/{id}/pdf/retry` تحت بادئة مساحة صاحبه. هذه عملية محلية لا تعيد البحث. العمل المدفوع الملتبس أو المنقطع لا يُعاد تلقائيًا بعد إعادة التشغيل؛ تبقى آخر نسخة ناجحة متاحة.

## التشخيص

| الحالة | ما يجب فحصه |
|---|---|
| قائمة فارغة ناجحة | عدد النتائج الخام، حدود النافذة، أحدث وقت نشر، فحص الصلة والتكرار |
| تأخر NewsData | توقيت المصدر وخطة الوصول الفعلية؛ لا تفترض أن تهيئة `paid` تمنح استحقاقًا |
| فشل المصدر مع نسخة قديمة | سبب الخطأ ووقت آخر نجاح؛ لا تسمّ المحاولة الفاشلة تحديثًا فارغًا ناجحًا |
| فشل بحث الويب الإضافي | `retrieval.web_search` وسبب الخطأ وحدود الحجز، مع إبقاء نتائج NewsData المفيدة |
| حد تطبيق | السقف والسجل والإعداد، ثم إعادة فحص صريحة إذا عولج السبب |
| حد مزود | رصيد الحساب أو فترة التهدئة؛ لا تتجاوزها بطلبات متكررة |
| تقرير متعثر | معرف المهمة، المرحلة الفعلية، الكود الآمن والمرجع؛ احتفظ بالتقرير السابق |
| إجابة جزئية | استعد المحادثة أو افحص المحاولة نفسها؛ لا تعرضها كإجابة مكتملة |
| سجل غير متاح لصاحب آخر | تحقق من ملكية الجلسة؛ لا توسّع الوصول لتجاوز 404 |

لا تنسخ المفاتيح أو أجسام ردود المزود الخاصة إلى سجلات عامة. توثيق API الكامل ومسارات المالك والزائر في [دليل الترقية](UPGRADE_2_1.md)، وحدود الخصوصية في [نموذج الأمان](security-model.md).
