## 1. الإعداد

يضع المالك `OPENAI_API_KEY` في `.env` محلي خاص أو في Environment الخاصة بخدمة Render. هذا هو مفتاح API الوحيد للبحث والتقارير والمحادثة. بيانات دخول الواجهة مستقلة عنه. لا تحتوي حزمة المصدر على قيم إنتاج، ولا يحتاج CI إليها.

| المتغير | القيمة الافتراضية أو الغرض |
|---|---|
| `APP_USERNAME` | اسم دخول المالك؛ اختر اسمًا بحروف لاتينية |
| `APP_PASSWORD` | كلمة مرور عشوائية طويلة |
| `OPENAI_API_KEY` | مفتاح OpenAI في الخادم فقط |
| `OPENAI_MODEL_NAME` | `gpt-6.1-sol` |
| `OPENAI_REASONING_EFFORT` | `low` |
| `MAX_OUTPUT_TOKENS` | `4096` للتقرير أو رد المحادثة، ضمن 128–8192 |
| `OPENAI_RESEARCH_MAX_OUTPUT_TOKENS` | `4096` لكل طلب بحث، ضمن 512–8192 |
| `AI_HUB_DATABASE_PATH` | ملف SQLite؛ في Render تحت `/var/data/ai-hub` |
| `MAX_REPORTS_PER_DAY` | `50` محاولة تقرير كحد أقصى |
| `DAILY_BUDGET_USD` | `5` للتقارير والمحادثة معًا |
| `MONTHLY_BUDGET_USD` | `100` للتقارير والمحادثة معًا |
| `SCHEDULER_ENABLED` | `false` حتى اعتماد المواعيد وتفعيلها |
| `ENABLE_API_DOCS` | `false`؛ يفضّل تفعيله محليًا فقط |

نجاح `/health` يثبت استجابة الخدمة. فحص `/v1/system` يعرض التهيئة دون طلب مدفوع؛ لا يثبت صلاحية المفتاح أو الرصيد أو الوصول إلى النموذج أو جودة البحث. تُراجع هذه الجوانب من الطلب الفعلي وسجله.

## 2. اللغة والمحادثة

يغيّر زرا **العربية / English** أعلى الصفحة لغة الواجهة واتجاهها، ولغة التقارير الجديدة. تغيير اللغة وحده لا يستدعي OpenAI ولا يترجم تقريرًا محفوظًا. لكل جدول لغة محفوظة مستقلة، والقيمة الافتراضية `ar`. يحتفظ الأرشيف بلغته الأصلية.

لإعداد تقرير، اختر المساعد واكتب الموضوع وفترة النشر المطلوبة في مربع المهمة، مثل «أخبار إيران المنشورة اليوم» أو فترة بتاريخين، ثم شغّل المساعد. يتضمن سياق المحادثة العام هذه الخطوات وموضع زري اللغة كي يشرح طريقة الاستخدام.

افتح المحادثة للمساعدة في استخدام المنصة أو فهم تقرير محفوظ. يمكن إنشاء محادثة مستقلة، والعودة إلى محادثات سابقة، وإرفاق تقرير مكتمل ثم إزالته. تُحفظ الرسائل في الخادم؛ يتلقى النموذج أحدث السياق المكتمل والتقرير المختار ضمن حدود الحجم، ولا يتلقى الأرشيف كله. المحادثة ترشد إلى المساعد المناسب للبحث الجديد، ولا تنفذ بحثًا حيًا أو تغيّر الإعدادات أو تشغّل الجداول من نافذتها.

كل رسالة مقبولة تستخدم طلب Responses واحدًا بلا أدوات. حد الرسالة 8000 حرف والعنوان 120 حرفًا. سياق النموذج حتى 20 دورًا مكتملًا ضمن 100000 بايت، وسياق التقرير المختار ضمن 30000 بايت، والطلب الكامل ضمن 200000 بايت. تبقى الرسائل الأقدم محفوظة حتى عند استبعادها من سياق النموذج. تظهر حالة انتظار حقيقية دون محاكاة بث النص.

رسائل الدردشة لها سجل تكلفة مستقل، ولا تدخل في حصة 50 تقريرًا ولا تظهر في أرشيف التقارير. لكنها تشارك التقارير الميزانية اليومية والشهرية. شرح الاستعمال والاستجابات في [دليل المحادثة واللغتين](CHAT_AND_LANGUAGES.md).

## 3. البحث والمصادر المعتمدة

يبقى `iran-news` مساعدًا واحدًا يجري طلب بحث موحدًا عبر جميع النطاقات المعتمدة، ثم يُنتج تقريرًا موحدًا؛ لا يُقسم البحث إلى طلبات أو مساعدين أو تقارير مستقلة لكل ناشر.

| المسار | الطلبات القصوى لكل مهمة |
|---|---|
| المساعدون الإخباريون الأربعة | طلب بحث واحد موحد عبر النطاقات الثمانية معًا، ثم تقرير عند توفر أدلة مقبولة؛ طلبا Responses كحد أقصى |
| مساعد آخر يحتاج إلى البحث | طلب بحث واحد ثم إجابة؛ طلبان كحد أقصى |
| مهمة بلا بحث | طلب نموذج واحد |
| رسالة محادثة | طلب نموذج واحد بلا أدوات |

المساعدون الإخباريون هم `iran-news` و`geopolitical-morning` و`uae-eu-trade-talks` و`economic-cultural-briefing`. يستخدم طلب البحث الواحد لكل مهمة القائمة التالية مجتمعة، دون تقسيم أو تنفيذ متوازٍ حسب الناشر:

| الناشر | النطاقات المسموح بها |
|---|---|
| Financial Times | `ft.com` |
| The Atlantic | `theatlantic.com` |
| Politico | `politico.com`، `politico.eu` |
| Wall Street Journal | `wsj.com` |
| The Daily Telegraph | `telegraph.co.uk` |
| الجزيرة | `aljazeera.com`، `aljazeera.net` |

طلب البحث الموحد مستقل عن سياق التقارير السابقة، ويسمح باستدعاء واحد لأداة `web_search`: القيم الثابتة `max_tool_calls=1` و`parallel_tool_calls=false` و`search_context_size=low` و`return_token_budget=default`. لا توجد إعادة تلقائية للطلب الفاشل. يُحجز البحث وطلب الصياغة المحتمل قبل بدء العمل، مع حدود منفصلة لكل طلب. [مرجع أداة البحث](https://developers.openai.com/api/docs/guides/tools-web-search).

توجّه تعليمات 1.4.1 النموذج إلى استعلام طبيعي موجز، مع تطبيق قائمة النطاقات في الأداة. لا يغيّر ذلك عدد الطلبات أو حدودها، ولا يُعد وحده إثباتًا لتحسن التغطية أو زيادة النتائج المقبولة.

تُجمع الأدلة من طلب البحث الموحد وتُزال التكرارات قبل صياغة التقرير. وجود جميع النطاقات في قائمة البحث لا يضمن العثور على مادة صالحة من كل ناشر. إذا فشل طلب البحث، تفشل المحاولة مع الاحتفاظ بكامل الاحتياطي ودون إعادة تلقائية. نجاح البحث دون دليل إخباري مقبول يعيد نتيجة بلا أخبار ولا يتبعه طلب صياغة إخباري إضافي.

يطبق البحث `allowed_domains`، ثم يفحص الخادم مضيف الرابط. تشمل السياسة النطاقات الفرعية الصحيحة وتستبعد أسماء مضللة مثل `ft.com.evil.test`. لا يتوسع البحث إلى ناشر آخر عند قلة الأدلة. يجب أن يكون رابط المقال مأذونًا من بيانات البحث الأصلية؛ يدعم التطبيع تمثيل المسار نفسه بصيغة Unicode أو percent encoding، ولا يمنح إذنًا لرابط جديد.

يربط المحلل ملاحظات المقال باستشهاده أو بعنوانه المنسوب إليه بوضوح، ويرفض اختلاط مصادر مختلفة في كتلة واحدة. في أخبار إيران يمكن إثبات الصلة من عنوان المقال أو ملاحظاته المباشرة؛ الإشارة العرضية وحدها غير كافية. ملاحظات البحث والتواريخ مستخلصة بواسطة النموذج، وليست نصوص ناشرين نزّلها التطبيق وفحصها حرفيًا. وجود رابط لا يثبت الوصول الكامل إلى مقال خلف اشتراك. راجع [وثائق مصادر البحث](https://developers.openai.com/api/docs/guides/tools-web-search#sources)، وراجع المعنى والتواريخ تحريريًا.

تغطي سياسة أخبار إيران المدن والمؤسسات والجهات المرتبطة بها، ولا تشترط ورود كلمة «إيران» في المقال. تشمل القرائن طهران/Tehran/Teheran وأصفهان وتبريز وبندر عباس والمؤسسات مثل الحرس الثوري، مع قراءة ملاحظات المقال نفسه. تشمل الموضوعات الشؤون المحلية والصحة والتعليم والثقافة والرياضة والبيئة وغيرها، إضافة إلى السياسة والاقتصاد. تُستبعد الإشارات العرضية والكلمات العامة الملتبسة؛ ليست أسماء المدن قائمة بحث مستقلة أو مصدرًا جديدًا.

### العدد والتواريخ والعرض

التغطية مفتوحة افتراضيًا بحسب الأدلة المتاحة، مع حد معالجة **20 بندًا للمجموع الكلي للأخبار والسياق**. لا يوجد هدف افتراضي من ستة أخبار ولا تُملأ القائمة بأخبار مختلقة. يمكن طلب عدد صحيح موجب صراحة؛ يُحفظ الهدف الأصلي ويُعلن النقص إذا لم تدعمه الأدلة أو تجاوز حد المعالجة.

في JSON، `item_count` هو العدد الفعلي و`bounded_item_limit=20`. للتغطية المفتوحة تكون `target_count` و`shortfall` بقيمة `null`. تعني `complete` اكتمال المخرج المقبول، ولا تعني حصر جميع الأخبار أو تمثيل كل ناشر. انعدام البنود الحالية يعطي `no_evidence`، ولا يثبت عدم وقوع أحداث.

تُحسب التغطية الحالية بحسب **تاريخ نشر المقال في الفترة المطلوبة بتوقيت دبي**. تاريخ الحدث حقل منفصل؛ قد يكون أقدم أو مستقبليًا أو غير معروف مع بقاء المقال المنشور داخل الفترة خبرًا حاليًا. تُعرض مواد ذات نشر أسبق في قسم السياق ولا تُحسب خبرًا حاليًا. تستمر فحوص الطابع الزمني الكامل ورفض وقت نشر مستقبلي أو غير صالح؛ لا يجوز إسقاط ساعة أو منطقة زمنية من المصدر لتجاوزها.

تُقبل صفحة تغطية حية رسمية مباشرة ومؤرخة كبند واحد من نوع `source_kind='live_coverage'`، مع عنوان وملخص ورابط الصفحة نفسها وعلامة **«تغطية حية» / “Live coverage”**. تبقى فحوص الإذن الأصلي للرابط والنطاق والصلة والتاريخ والتكرار. لا تُقبل الصفحة الرئيسية أو صفحة القسم أو فهرس البث العام، ولا تُحوّل تحديثات الصفحة الواحدة إلى أخبار متكررة. تصف العلامة نوع المصدر، ولا تعني أن التقرير المحفوظ يتحدث تلقائيًا أو أن الصفحة ما زالت حية الآن.

يعرض الخبر عنوانًا وملخصًا واسم الناشر وتاريخ النشر ورابطًا مباشرًا إلى المقال الرسمي. يظهر السياق في قسم منفصل. فتح تقرير قديم أو نسخه أو تنزيله لا يعيد توليده. يحتفظ المساعدون غير الإخباريين بوظائفهم الأصلية؛ مساعد WhatsApp يجهز النص فقط ولا يرسله.

## 4. المحاسبة وإعادة الإرسال

حد **50 محاولة تقرير مقبولة في يوم دبي** يجمع كل المساعدين والتشغيل اليدوي والمجدول، بما في ذلك الفشل بعد القبول. لا يشمل رسائل المحادثة. تتحقق معاملة SQLite واحدة من الميزانية المشتركة قبل حجز التكلفة وإجراء طلب مدفوع. تجاوز الميزانية يرفض العمل قبل الاتصال بالمزود.

يبقى احتياطي العمل المعلق أو الفاشل أو ذي الاستخدام غير المعروف. عند اكتمال بيانات الاستخدام وفئة الخدمة وحدود التوكنات، يُحتسب مجموع استخدام الطلبات ورسوم البحث ويُحدّث السجل. تعرض `/v1/usage` إجمالي الدولار المشترك مع تفصيل `report_estimated_cost_usd` و`chat_estimated_cost_usd`؛ تظل `attempts` و`remaining` خاصتين بالتقارير. يبدأ اليوم والشهر عند حدودهما بتوقيت `Asia/Dubai`.

قيم التسعير المضبوطة في المصدر استنادًا إلى المراجعة المسجلة في 19 أكتوبر 2026:

| المتغير | القيمة الافتراضية |
|---|---:|
| `OPENAI_PRICING_MODEL` | `gpt-6.1-sol` |
| `OPENAI_INPUT_USD_PER_MILLION` | 2 دولار لكل مليون token |
| `OPENAI_OUTPUT_USD_PER_MILLION` | 10 دولارات لكل مليون token |
| `OPENAI_WEB_SEARCH_PRICE_USD_PER_CALL` | 0.01 دولار لكل استدعاء أداة بحث |

يستخدم التطبيق معامل إدخال محافظًا 1.25، أي 2.50 دولار لكل مليون token عند القيم الافتراضية، مع فئة الخدمة القياسية ودون افتراض خصم cache. رسم استدعاء أداة البحث الواحد 0.01 دولار، وتضاف إليه توكنات النموذج ومحتوى البحث؛ **هذا الرسم ليس تكلفة التقرير أو الاحتياطي الكامل**. راجع [صفحة النموذج](https://developers.openai.com/api/docs/models/gpt-6.1-sol) و[التسعير الرسمي](https://developers.openai.com/api/docs/pricing) قبل تغيير النموذج أو أسعاره. يلزم ربط الأسعار باسم النموذج الصحيح.

يشمل حجز الخبر طلب البحث الموحد وطلب التقرير المحتمل، مع احتياطي محافظ لسياق البحث وحدود النموذج. قد يكون الاحتياطي أكبر كثيرًا من التكلفة النهائية عند اكتمال الاستخدام. يعمل حدا 5 دولارات يوميًا و100 دولار شهريًا معًا؛ لا يضمن سقف 50 محاولة تنفيذ العدد كاملًا. السجل تقديري داخل التطبيق ولا يشمل Render أو الضرائب أو استخدام المفتاح خارج AI HUB. فاتورة OpenAI مرجع الفوترة الفعلية.

يحمي `Idempotency-Key` الطلب من التكرار المدفوع. إعادة المفتاح والجسم نفسيهما تعيد النتيجة المحفوظة أو حالة المحاولة القائمة؛ تغيير المحتوى أو اللغة مع المفتاح نفسه مرفوض. في الدردشة تدخل حالة اختيار التقرير أيضًا في المطابقة. لا يُعاد تنفيذ مفتاح فاشل أو منقطع تلقائيًا؛ المفتاح الجديد طلب جديد قابل للفوترة.

تسمح المحادثة بدور معلق واحد. إعادة فتحها تُظهر الرسالة الفعلية وحالتها دون اختلاق رد مساعد. بعد أكثر من 15 دقيقة يُسجل الدور العالق `interrupted` عند استعادة الحالة مع بقاء الاحتياطي. لا تُلحق إجابة قديمة متأخرة بتاريخ محادثة بدأ فيه دور جديد.

## 5. الجدولة

الأوقات ثابتة بتوقيت دبي، مثل `08:00` و`16:00`. مثال `POST /v1/schedules`:

```json
{
  "name": "نشرة أخبار إيران",
  "agent_id": "iran-news",
  "task": "أهم الأخبار المنشورة اليوم من المصادر المعتمدة، مع الملخصات والروابط والتواريخ.",
  "language": "ar",
  "times": ["08:00", "16:00"],
  "enabled": false
}
```

لتشغيل جدول معتمد، يلزم `enabled=true` للجدول و`SCHEDULER_ENABLED=true` في البيئة ثم إعادة التشغيل. حدّث قيمة Blueprint أيضًا حتى لا تعكسها مزامنة لاحقة. الحالة الافتراضية الحالية متوقفة؛ لا يفعّل تحديث 1.4.1 الجداول تلقائيًا.

- مجموع أوقات الجداول المفعلة لا يتجاوز 50 وقتًا يوميًا؛ المحاولات اليدوية تشاركها الحصة الفعلية.
- يفحص المجدول المواعيد كل نحو 15 ثانية ويشغّل التقارير بالتتابع.
- مهلة الموعد المتأخر 5 دقائق؛ تُتجاوز المواعيد الأقدم دون دفعة تعويضية.
- الإنشاء والتعديل وإعادة التفعيل تسري على الأوقات التالية فقط.
- الموعد المحجوز لا يتكرر تلقائيًا بعد إعادة التشغيل أو الفشل.
- تستمر الخدمة بنسخة واحدة وعامل Uvicorn واحد؛ التشغيل المحلي يتوقف عند إطفاء الجهاز.

## 6. مرجع API والفحص

كل مسارات `/v1/*` تتطلب مصادقة HTTP Basic للمالك. استخدم HTTPS خارج جهازك. المهام والرسائل محدودة بـ8000 حرف؛ الحقول غير المعروفة مرفوضة.

| المسار | الغرض |
|---|---|
| `GET /health` | فحص استجابة عام بلا اتصال بالمزود |
| `GET /v1/agents` و`GET /v1/system` | المساعدون وحالة التهيئة |
| `POST /v1/agents/{id}/run` | تقرير جديد بالجسم `{task, language}` |
| `GET /v1/reports` و`GET /v1/reports/{id}` | الأرشيف ونتيجة التقرير |
| `GET /v1/reports/{id}/download?format=md` أو `format=json` | تنزيل محفوظ دون توليد |
| `GET /v1/usage` | حصص التقارير وتكاليف التقارير والمحادثة |
| `GET/POST /v1/chat/conversations` | قائمة المحادثات وإنشاء محادثة مجانية |
| `GET /v1/chat/conversations/{id}` | الرسائل والحالة؛ يدعم `limit` و`before` |
| `POST /v1/chat/conversations/{id}/messages` | رسالة مع `Idempotency-Key` مطلوب و`report_id` اختياري |
| `GET/POST /v1/schedules` و`PATCH/DELETE /v1/schedules/{id}` | إدارة الجداول ولغتها |
| `GET /v1/schedule-occurrences` | سجل تنفيذ المواعيد وتجاوزها |

شغّل `python -m pytest` للفحوص الاصطناعية، ثم `python scripts/smoke_test.py` لفحص الخدمة دون توليد. الخيار `--live --agent iran-news` يطلب **تقريرًا واحدًا قابلًا للفوترة**. يطبع السكربت معرّف الطلب قبل التنفيذ ويمكن إعادة استخدامه عبر `--request-id` لمراجعة الطلب نفسه. تشغيله بمعرّف جديد محاولة جديدة. افحص الأرشيف والبحث والتواريخ بعد الطلب؛ HTTP ناجح أو وجود مراجع كثيرة لا يعني وجود أخبار مقبولة.

## 7. الديمومة والنسخ الاحتياطي

تحفظ SQLite التقارير والمحادثات والرسائل والجداول وكلا سجلي التكلفة. أضاف تحديث 1.4.0 جداول الدردشة وعمود لغة الجداول مع افتراضي عربي دون حذف السجلات السابقة. تُحفظ بصمات طلبات التقارير العربية القديمة كما كانت. خذ نسخة متسقة قبل التحديثات التشغيلية:

```bash
python scripts/backup_database.py --output ./backups/AI_HUB_Backup_2026-10-20.sqlite3
```

السكربت يستخدم واجهة SQLite للنسخ ويفحص سلامة النسخة ويرفض الكتابة فوق ملف قائم. لا تنسخ ملف القاعدة الرئيسي وحده أثناء الكتابة لأن WAL قد يحوي بيانات حديثة. في Render يقع الملف وملفات WAL تحت `/var/data/ai-hub` على القرص نفسه. انقل النسخة إلى وجهة خاصة خارج القرص؛ وجودها على القرص نفسه لا يحمي من فقدانه. [مرجع Render للأقراص](https://render.com/docs/disks).

اختبر الاستعادة في نسخة منفصلة والمجدول متوقف، وافحص التقارير والمحادثات والحصة. لا تستبدل قاعدة إنتاج وهي مستخدمة. تُستبعد القواعد والنسخ والبيانات السرية من Git وحزمة المصدر.

## 8. التشخيص

| الحالة | الإجراء |
|---|---|
| `401` أو `auth_not_configured` | راجع بيانات دخول المالك في الخدمة |
| `runtime_not_configured` أو ربط أسعار غير صحيح | راجع المفتاح واسم النموذج والأسعار دون نسخ القيم السرية إلى الدعم |
| أخبار قليلة أو صفر | راجع فترة النشر وأدلة المقالات وأسباب الاستبعاد؛ عدد المراجع وحده لا يكفي |
| `openai_timeout` أو `openai_api_error` | راجع المحاولة المحفوظة وكود الخطأ؛ لا تُعد الإرسال تلقائيًا بمعرّف جديد |
| `429` | راجع حصة التقارير أو الميزانية المشتركة لليوم والشهر |
| `409` لمعرّف الطلب | افحص الحالة المحفوظة قبل طلب محاولة جديدة |
| `conversation_busy` أو `chat_in_progress` | افتح المحادثة وتحقق من الدور المعلق |
| `chat_history_changed` | حدّث المحادثة؛ لم تُرسل المحاولة المتعارضة إلى OpenAI |
| `chat_report_not_found` أو `chat_report_unavailable` | اختر تقريرًا محفوظًا مكتملًا |
| فقدان السجل بعد النشر | راجع القرص ومسار SQLite وملفات WAL |
| الجدولة لا تعمل | راجع التفعيل العام وتفعيل الجدول وتوقيت دبي والميزانية |

احتفظ بالكود الآمن ومعرّف التقرير أو الدور ووقت حدوث المشكلة. لا تنسخ مفاتيح API أو كلمات المرور أو رؤوس Authorization أو جسم خطأ المزود إلى محادثة الدعم.
