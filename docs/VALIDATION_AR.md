## 3. أوامر التحقق

بعد إعداد البيئة كما في `README.md`:

```bash
python -m pytest
python scripts/validate_blueprint.py
python scripts/package_handoff.py --output dist/AI_HUB_Project.zip
```

يمكن تمرير نسخة محفوظة من مخطط Render الرسمي إلى `--schema` للتحقق دون إنترنت. التحقق البنيوي لا ينشئ موارد ولا يثبت قبول إعدادات الحساب أو صحة المفتاح. حزمة التسليم تضم المصدر وملفّي المتابعة وتستبعد بيانات التشغيل والأسرار.

## 4. ما بقي للاختبار الحي

1. اكتمال اختبارات التحديث وCI، ثم التحقق من أن Render يشغّل commit الذي يحتوي `web_search`.
2. التحقق من ضبط بيانات دخول المالك و`OPENAI_API_KEY` في البيئة الخاصة، مع بقاء المجدول متوقفًا.
3. إجراء تقرير حي واحد ومراجعة روابط المصادر وتواريخها وعدد البنود والتنبيهات واستخدام المرحلتين وأداة البحث.
4. مقارنة تقدير السجل بالاستخدام الظاهر لدى OpenAI، مع تمييز الاحتياطي عن التكلفة المقدّرة بعد اكتمال الطلب.
5. التحقق من بقاء التقرير والحصة بعد إعادة تشغيل الخدمة على القرص الدائم.
6. تفعيل المواعيد اليومية بعد نجاح ما سبق واعتماد أوقاتها.

المصادر المسموح الاستشهاد بها تؤخذ من بيانات أداة البحث. الملاحظات المستخلصة منها والتواريخ قد تعتمد على قراءة النموذج؛ لا يثبت ذلك صحة كل استنتاج أو استقلال كل مصدر. حد 50 سقف للمحاولات المقبولة، ولا يضمن اكتمال 50 تقريرًا أو توافر 300 خبر فريد يوميًا.
