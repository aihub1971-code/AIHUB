## 2. المصدر وCI

يقع `app/` بجانب `render.yaml` و`requirements.txt` و`agents.json` في جذر المستودع. يبني Render الملفات مباشرة؛ ZIP للتسليم فقط ولا يُستخرج أثناء البناء.

للحصول على نسخة أولى:

```bash
git clone https://github.com/aihub1971-code/AIHUB.git
cd AIHUB
```

استخدم نسخة العمل الموجودة إن توفرت، واحمِ التغييرات المحلية. راجع الفرق في فرع مستقل وادمج التحديث عبر مراجعة وCI دون `force push`. بعد إعداد Python 3.12 وبيئة افتراضية:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest
node --check app/static/app.js
node --check app/static/chat.js
node --check app/static/i18n.js
node tests/test_ui_news.js
node tests/test_ui_chat.js
python scripts/validate_blueprint.py
python scripts/package_handoff.py --output dist/AI_HUB_Project.zip
```

تنفذ `.github/workflows/tests.yml` هذه الفحوص وتجهيز الحزمة المرتبطة بالـcommit. اختبارات Python وواجهة JavaScript تستخدم بيانات اصطناعية ولا تحتاج مفاتيح إنتاج أو طلبات OpenAI مدفوعة. Node.js مطلوب لفحوص الواجهة وليس لخدمة Python في الإنتاج. يحتفظ CI بحزمة المصدر لمدة 7 أيام؛ النتيجة الخاصة بالـcommit المطلوب هي مرجع النجاح، دون نقل أرقام اختبارات إصدار سابق إليه.

يقرأ فاحص Blueprint [مخطط Render الرسمي](https://render.com/schema/render.yaml.json) دون إنشاء خدمة. يمكن تمرير ملف مخطط محفوظ عبر `--schema` للعمل دون الشبكة. الإعداد `autoDeployTrigger: checksPass` يتبع الفرع بعد نجاح الفحوص؛ عالج سبب فشل CI قبل تجاوزه بنشر آخر. [مرجع Blueprint](https://render.com/docs/blueprint-spec).

## 3. إعداد الخدمة المرجعي

| الإعداد | القيمة |
|---|---|
| المستودع / الفرع | `aihub1971-code/AIHUB` / `main` |
| Runtime / المنطقة | Python 3.12 / Frankfurt |
| Root Directory | فارغ؛ المصدر في الجذر |
| Build | `python -m pip install -r requirements.txt` |
| Start | `python -m uvicorn app.main:app --host 0.0.0.0 --port $PORT --workers 1` |
| Compute | `0.5c-512mb`؛ نسخة واحدة وعامل واحد |
| Health | `/health` |
| القرص | `ai-hub-data`، 1 GB عند `/var/data/ai-hub` |
| SQLite | `/var/data/ai-hub/ai-hub.sqlite3` |
| المجدول | `SCHEDULER_ENABLED=false` |
| ميزانية التطبيق | 5 دولارات يوميًا و100 دولار شهريًا للتقارير والمحادثة معًا |

السعر المعروض عند إنشاء الخدمة كان 7 دولارات شهريًا للحوسبة و0.25 دولار للقرص، أي 7.25 دولارات قبل الإضافات والضرائب وOpenAI. هذه معلومة الإنشاء وليست عرض سعر جديدًا. [أسعار Render](https://render.com/pricing)، و[خطط الحوسبة](https://render.com/docs/compute-plans). ميزانية التطبيق لا توقف رسوم الاستضافة، وحد 50 محاولة تقرير ليس اختبار تحميل أو وعدًا بإنتاج 50 تقريرًا ضمن الميزانية.

يحدد `.python-version` سلسلة Python 3.12؛ متغير `PYTHON_VERSION` الموجود في الخدمة يتقدم عليه وفق [ترتيب الأولوية](https://render.com/docs/python-version). لا تضف عمال Uvicorn أو نسخ Render لتوسيع التشغيل دون إعادة تصميم التخزين والجدولة.

## 4. تطبيق التحديث وترحيل البيانات

1. خذ نسخة SQLite متسقة من الخدمة الحالية وفق [دليل التشغيل](OPERATIONS_AR.md)، وانقلها إلى وجهة خاصة خارج قرص الخدمة.
2. تحقق من نجاح CI للـcommit المقصود ووجود مصدر 1.4.1 في الفرع الذي تتبعه الخدمة.
3. حافظ على القرص ومسار قاعدة البيانات الحاليين. راجع مزامنة Blueprint عند تغير تعريفه؛ لا تستبدل الخدمة أو القاعدة.
4. استخدم قيم `APP_USERNAME` و`APP_PASSWORD` و`OPENAI_API_KEY` الموجودة الصالحة. المحادثة لا تتطلب مفتاحًا أو خدمة إضافية. تبقى الميزانية 5/100 والمجدول متوقفًا.
5. تابع النشر، ثم طابق commit الخدمة ونسختها الفعلية مع المصدر؛ لا تعتمد على رقم نسخة في حزمة ZIP وحده.

تُهيأ SQLite عند بدء التطبيق. أضاف ترحيل 1.4.0 جداول المحادثات والرسائل والتكلفة و`schedules.language` مع `ar` للجداول السابقة. يحتفظ التحديث بالتقارير القديمة وبصمات طلباتها العربية وبحصة التقارير. لا يحتاج إلى حذف القاعدة أو تصفير سجل الاستخدام، ولا يستورد تلقائيًا قاعدة مشروع قديم غير مطابق.

حقل الأسرار `sync: false` يطلب القيم أثناء إنشاء Blueprint أول مرة فقط. تُعدل القيم لاحقًا من Environment، ولا توضع في YAML أو Git أو لقطات الشاشة. [آلية أسرار Blueprint](https://render.com/docs/blueprint-spec#prompting-for-secret-values).

## 5. فحص ما بعد النشر

فحص قراءة فقط، مع إعداد بيانات المالك في بيئة محلية خاصة:

```bash
python scripts/smoke_test.py --base-url https://ai-hub-vc8w.onrender.com
```

تحقق من النسخة والـcommit والمصادقة والمساعدين والأرشيف. جرّب تبديل العربية والإنجليزية وفتح تقرير محفوظ وإنشاء محادثة فارغة؛ هذه الخطوات لا تتطلب توليدًا مدفوعًا. افحص ديمومة الجداول ولغتها والمحادثات عند إعادة الفتح.

للتقرير الحي المحدود القابل للفوترة بعد اكتمال النشر:

```bash
python scripts/smoke_test.py --base-url https://ai-hub-vc8w.onrender.com --live --agent iran-news
```

طلب رسالة فعلية في المحادثة قابل للفوترة أيضًا. راجع حالة الانتظار والرد المحفوظ والميزانية المشتركة دون تكرار الإرسال تلقائيًا. عند انتهاء المهلة، افحص السجل وأعد المفتاح نفسه إذا أردت مراجعة المحاولة القائمة؛ المفتاح الجديد محاولة جديدة. راجع عنوان كل خبر وملخصه ورابطه وتاريخ نشره. صفر الأخبار لا يثبت عدم وجود أحداث، وكثرة مراجع البحث لا تثبت قبول مقالات صالحة.

سجل نتائج الفحص الفعلية والـcommit في `docs/VALIDATION_AR.md`. الأوامر أعلاه إجراءات مقترحة، وليست إثباتًا أنها نُفذت على 1.4.1.

## 6. حدود الديمومة والتشغيل

القرص متاح للخدمة أثناء التشغيل، وليس أثناء البناء أو أوامر ما قبل النشر أو لخدمة أخرى. إعادة النشر لخدمة ذات قرص قد تسبب انقطاعًا قصيرًا. [وثائق Render للأقراص](https://render.com/docs/disks).

يحتفظ العمل المنقطع باحتياطيه ولا يُعاد تلقائيًا. يتجاوز المجدول المواعيد الأقدم من مهلة السماح بدل تعويضها بدفعة طلبات. أبقِ المجدول متوقفًا حتى اعتماد مواعيده، وراجع التفعيل في البيئة وBlueprint معًا عند تشغيله لاحقًا. اختبر الاستعادة في نسخة منفصلة؛ لا تستبدل ملف إنتاج وهو مستخدم.
