# ابدأ من هنا — AI HUB

المصدر المباشر في [aihub1971-code/AIHUB](https://github.com/aihub1971-code/AIHUB). افتح `README.md` أولًا لأوامر Windows وLinux وmacOS. البحث على الويب والتوليد يعملان عبر OpenAI API بمفتاح واحد. البحث محصور في الجهات المعتمدة، وعدد الأخبار يتبع الأدلة المتاحة دون عدد إلزامي.

يعرض إصدار 1.3.0 كل خبر بعنوان بارز وملخص قصير واسم الناشر والتاريخ وزر «فتح الخبر على الموقع الرسمي». تُفصل مواد السياق السابق، وتبقى التقارير المحفوظة قابلة للعرض والتنزيل دون إعادة توليد. يجمع المساعد الإخباري الأدلة من جولتين مستقلتين للمصادر المعتمدة قبل إعداد التقرير.

## خطوات التشغيل

1. استخدم نسخة المصدر التي تتضمن تحديث `web_search` بعد مراجعة اختباره، وأنشئ بيئة Python 3.12 وثبّت `requirements-dev.txt`.
2. انسخ `.env.example` إلى `.env`، واضبط `APP_USERNAME` و`APP_PASSWORD` و`OPENAI_API_KEY` بنفسك. المفتاح نفسه يشغّل البحث والتوليد.
3. اترك `SCHEDULER_ENABLED=false`، وشغّل الاختبارات والتطبيق، ثم جرّب تقريرًا حيًا واحدًا.
4. راجع الروابط والتواريخ وعدد الأخبار وتقدير الاستخدام، وتحقق من حفظ التقرير.
5. خدمة Render موجودة بالفعل في مساحة **AI's workspace** على [ai-hub-vc8w.onrender.com](https://ai-hub-vc8w.onrender.com). تابع نشر النسخة الجديدة على الخدمة نفسها وفق `DEPLOYMENT_AR.md`؛ حالتها الوظيفية الحية لا تُثبت بمجرد إنشائها.
6. بعد نجاح الاختبار الحي والتحقق من بقاء البيانات على القرص، أنشئ أوقات الجدولة وفعّلها. الحد الأعلى 50 محاولة يوميًا لجميع المساعدين معًا.

## حدود التحقق

اجتاز المصدر المحلي 1.3.0 عدد **231 اختبار Python و7 فحوص لعارض الأخبار**، إضافة إلى فحص بنية JavaScript. التفاصيل في `VALIDATION_AR.md`، وتُراجع نتيجة commit الحالي في [Actions](https://github.com/aihub1971-code/AIHUB/actions). بيانات معاينة الواجهة مصطنعة، والتجربة الحية السابقة التي أعادت خبرين من الجزيرة تخص 1.2.0؛ لا تُنسب إلى مسار البحث المحدّث.

تقارير الأخبار تعرض العدد الفعلي ضمن حد معالجة 20 بندًا، دون اشتراط الوصول إليه. البحث محصور في Financial Times وThe Atlantic وPolitico وWall Street Journal وThe Daily Telegraph والجزيرة؛ [النطاقات المعتمدة](OPERATIONS_AR.md#3-المصادر-المعتمدة-وعدد-الأخبار). لا يُضمن تمثيل كل جهة أو إتاحة مواد الاشتراك، والملاحظات المستخلصة تحتاج مراجعة للمحتوى والتواريخ. العدد 50 سقف محاولات ولا يضمن اكتمال 50 تقريرًا كل يوم.

ميزانية الطلبات الافتراضية 5 دولارات يوميًا و100 دولار شهريًا هي تقدير داخل التطبيق. الاستضافة والقرص لهما تكلفة أساسية مستقلة قدرها 7.25 دولارات شهريًا حسب إعداد Render المعروض عند الإنشاء؛ راجع [الأسعار](https://render.com/pricing) للإضافات والتغييرات.

التفاصيل في `DEPLOYMENT_AR.md` و`OPERATIONS_AR.md` و`security-model.md`. أدخل كلمة المرور ومفتاح API في البيئة الخاصة فقط.
