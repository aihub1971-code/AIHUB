# AI HUB 2.0 — ابدأ من هنا

ابدأ من [README](../README.md) لأوامر Windows وLinux وmacOS. المصدر في [aihub1971-code/AIHUB](https://github.com/aihub1971-code/AIHUB)، والخدمة القائمة [AI HUB](https://ai-hub-vc8w.onrender.com). تصف الوثيقة مصدر 2.0 قبل إثبات نشره؛ [سجل التحقق](VALIDATION_AR.md) هو مرجع الحالة الفعلية.

## ما الذي تفعله الواجهة الجديدة؟

افتح `/` دون اسم مستخدم أو كلمة مرور. اختر واحدًا من المساعدين الـ13، وراجع موضوعه الافتراضي أو عدّله. تظهر مهمة خلفية بمراحل البحث وفحص المصادر والتحليل وإعداد PDF. يبقى آخر تقرير ناجح متاحًا أثناء التحديث، ويمكن فتح النسخ السابقة وتنزيل ملفاتها دون إعادة بحث.

العربية والإنجليزية متاحتان للواجهة والتقارير والمحادثة. لكل تقرير لغة محفوظة؛ تغيير لغة الواجهة لا يعيد توليده أو يترجمه تلقائيًا. المحادثة داخل المساعد تفهم التقرير المعروض تلقائيًا، ويمكن للمحادثة العامة الاستفادة من تقارير الجلسة نفسها. السؤال الذي يحتاج معلومات أحدث قد ينشئ مهمة بحث جديدة واضحة الحالة.

تبقى `/admin` لوحة المالك المحمية. الواجهة العامة لا تعرض التكاليف أو مفاتيح المزود أو أرشيف الإدارة أو تقارير جلسة أخرى.

## السياسة الحالية للأخبار

مساحة 2.0 تستخدم **OpenAI web_search وفحص صفحات الناشرين**، بلا NewsData وبلا قائمة مصادر ثابتة. نافذة الأخبار آخر **12 ساعة** عند تقديم المهمة. يلزم وقت نشر كامل موثق مع منطقة زمنية، ولا يكفي تاريخ اليوم أو الزحف أو التحديث العام.

الحد **20 خبرًا بعد التحقق والصلة وإزالة التكرار**. قد يكون العدد أقل أو صفرًا؛ لا تُستكمل النتائج بمادة قديمة. التغطية الحية تحتاج إدخالًا ذا توقيت نشر مثبت. يبقى مساعد إيران واحدًا للصراع والدبلوماسية والتداعيات، مع تقديرات منفصلة لإيران والولايات المتحدة والإمارات.

التاريخ له دليل قراءة ومراجع أقدم موسومة بخلفية، والقصة لها لوحة إبداعية ومراجع وألوان واتجاه بصري. محاضر الاجتماعات وواتساب والترجمة تعمل من النص الذي تلصقه فقط، دون الوصول إلى حساب أو تسجيل.

## التفعيل والنشر

1. استخدم Python 3.12 وثبّت التبعيات من جذر المصدر، بما فيها متطلبات PDF والخطوط المرفقة وترخيصها.
2. ضع `OPENAI_API_KEY` وبيانات المالك `APP_USERNAME` و`APP_PASSWORD` في البيئة الخاصة. لا تحتاج المساحة الجديدة إلى `NEWSDATA_API_KEY`.
3. استخدم الخدمة والقرص الحاليين، وقاعدة البيانات `/var/data/ai-hub/ai-hub.sqlite3`. توجد ملفات PDF في `reports/` بجانبها.
4. إعدادات 2.0 المستهدفة: `REPORT_JOB_WORKERS=2` داخل **عملية Uvicorn واحدة**، و`MAX_REPORTS_PER_DAY=50`، و`DAILY_BUDGET_USD=900`، و`MONTHLY_BUDGET_USD=28000`. هذه سقوف تحفظ الحجز المحافظ، وليست فاتورة متوقعة. اترك `SCHEDULER_ENABLED=false`.
5. بعد نجاح الاختبارات وCI والنشر، راجع تقريرًا فعليًا ومصادره وتوقيته وPDF ومحادثته، وسجّل النتيجة الفعلية في `docs/VALIDATION_AR.md`.

راجع [دليل النشر](DEPLOYMENT_AR.md). لا يكفي نجاح `/health` لإثبات جودة البحث أو صلاحية رصيد OpenAI. أوامر smoke القديمة تخص API السابق ولا تختبر مساحة 2.0.

## الاستخدام المحفوظ والأعطال

جلسة المتصفح تملك تقاريرها ومحادثاتها وPDF؛ حذف ملف الجلسة لا ينشئ حساب استعادة عبر جهاز آخر. عند غموض طلب، افحص المهمة القائمة ولا ترسل محاولة مدفوعة جديدة تلقائيًا. إذا فشل PDF بعد نجاح التقرير، أعد إخراجه من النسخة المحفوظة دون بحث جديد.

تبقى وحدات وواجهات NewsData القديمة للتوافق والأرشيف فقط؛ إعدادات 48 ساعة والإرفاق اليدوي وحد النتائج الخام السابق لا تصف المساحة الجديدة. راجع [التشغيل](OPERATIONS_AR.md)، [المحادثة واللغتين](CHAT_AND_LANGUAGES.md)، و[نموذج الأمان](security-model.md).
