# ابدأ من هنا — AI HUB

المصدر المباشر في [aihub1971-code/AIHUB](https://github.com/aihub1971-code/AIHUB). افتح `README.md` أولًا لأوامر Windows وLinux وmacOS. البحث على الويب والتوليد يعملان عبر OpenAI API بمفتاح واحد. البحث محصور في الجهات المعتمدة، وعدد الأخبار يتبع الأدلة المتاحة دون عدد إلزامي.

يعرض مصدر 1.4.3 كل خبر بعنوان بارز وملخص قصير واسم الناشر والتاريخ وزر «فتح الخبر على الموقع الرسمي». تُفصل مواد السياق السابق، ويعرض قسم «المصادر في هذا التقرير» المطوي أعداد الأخبار والسياق المقبول من كل ناشر. تبقى التقارير المحفوظة قابلة للعرض والتنزيل دون إعادة توليد، ولا يُضاف إليها ادعاء تغطية إذا غابت بياناتها.

## خطوات التشغيل

1. استخدم نسخة المصدر التي تتضمن تحديث `web_search` بعد مراجعة اختباره، وأنشئ بيئة Python 3.12 وثبّت `requirements-dev.txt`.
2. انسخ `.env.example` إلى `.env`، واضبط `APP_USERNAME` و`APP_PASSWORD` و`OPENAI_API_KEY` بنفسك. المفتاح نفسه يشغّل البحث والتوليد.
3. اترك `SCHEDULER_ENABLED=false`، وشغّل الاختبارات والتطبيق، ثم جرّب تقريرًا حيًا واحدًا.
4. راجع الروابط والتواريخ وعدد الأخبار وتقدير الاستخدام، وتحقق من حفظ التقرير.
5. خدمة Render موجودة بالفعل في مساحة **AI's workspace** على [ai-hub-vc8w.onrender.com](https://ai-hub-vc8w.onrender.com). تابع نشر النسخة الجديدة على الخدمة نفسها وفق `DEPLOYMENT_AR.md`؛ حالتها الوظيفية الحية لا تُثبت بمجرد إنشائها.
6. بعد نجاح الاختبار الحي والتحقق من بقاء البيانات على القرص، أنشئ أوقات الجدولة وفعّلها. الحد الأعلى 50 محاولة يوميًا لجميع المساعدين معًا.

## حدود التحقق

لإصدار المصدر **1.4.3** فحوص مستقلة مسجلة في [VALIDATION_AR](VALIDATION_AR.md) و[Actions](https://github.com/aihub1971-code/AIHUB/actions). الأعداد النهائية والنتيجة الحية لهذا التحديث تُثبت بعد الفحص؛ لا تُنقل إليه نتائج إصدار سابق أو بيانات معاينة اصطناعية.

تقارير الأخبار تعرض العدد الفعلي ضمن حد معالجة 20 بندًا، دون اشتراط الوصول إليه. يبدأ البحث باكتشاف موحد عبر الجهات المعتمدة، مع متابعة اختيارية مستقلة واحدة بعد اكتشاف مكتمل: تُجمع نطاقات الناشرين غير الممثلين في مرشح واحد لتوسيع التنوع، أو تُستخدم النطاقات الثمانية كاملة لاستكمال الأدلة بعد استخلاص فارغ؛ ثم يُصاغ تقرير واحد إذا توفرت مصادر. تظل Financial Times وThe Atlantic وPolitico وWall Street Journal وThe Daily Telegraph والجزيرة قائمة المصادر؛ [تفاصيل التشغيل](OPERATIONS_AR.md#3-البحث-والمصادر-المعتمدة). لا يُضمن تمثيل كل جهة أو إتاحة مواد الاشتراك، ولا يضمن سقف 50 محاولة إكمال 50 تقريرًا كل يوم.

على خط الأساس المنشور 1.4.2، أعاد طلب إيران خبرًا واحدًا من الجزيرة وطلب عالمي بالإنجليزية صفر أخبار مقبولة؛ التحقق الحي من 1.4.3 لم يُسجل بعد. لا تتضمن استعلامات أخبار اليوم تاريخًا تقويميًا أو سنة، مع الاحتفاظ بفترة النشر المطلوبة لفحص النتائج، ويمكن أن تتبع البحث العربي متابعة بالإنجليزية دون تغيير لغة التقرير. عند فشل متابعة اختيارية مع وجود أدلة أولية، يعرض التقرير ما يجتاز الفحوص مع تنبيه، وتبقى التكلفة المحتاطة كاملة.

يُعالج تاريخ نشر صريح متبوع بوصف عربي محدد يفيد غياب الساعة، مع بقاء فحوص التوقيت الأصلية ومنع حذف ساعة أو منطقة زمنية متاحة. لا يثبت هذا الإصلاح وحده تحسن البحث الحي.

ميزانية الطلبات الافتراضية 5 دولارات يوميًا و100 دولار شهريًا هي تقدير داخل التطبيق. الاستضافة والقرص لهما تكلفة أساسية مستقلة قدرها 7.25 دولارات شهريًا حسب إعداد Render المعروض عند الإنشاء؛ راجع [الأسعار](https://render.com/pricing) للإضافات والتغييرات.

التفاصيل في `DEPLOYMENT_AR.md` و`OPERATIONS_AR.md` و`security-model.md`. أدخل كلمة المرور ومفتاح API في البيئة الخاصة فقط.
