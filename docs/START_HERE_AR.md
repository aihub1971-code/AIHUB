# ابدأ من هنا — AI HUB

المشروع موجود في مجلد `ai-hub` داخل الحزمة. افتح `README.md` أولًا؛ يتضمن أوامر Windows وLinux وmacOS.

## خطواتك بالترتيب

1. أنشئ بيئة Python 3.12 وثبّت `requirements-dev.txt`.
2. انسخ `.env.example` إلى `.env` وضع اسم مستخدم وكلمة مرور خاصة ومفتاحي OpenAI وTavily بنفسك.
3. اترك `SCHEDULER_ENABLED=false`، وشغّل الاختبارات والتطبيق، ثم جرّب تقريرًا حيًا واحدًا.
4. راجع مصادر التقرير وعدده واستهلاكه وسجله الدائم.
5. ارفع الكود إلى مستودع GitHub الخاص الصحيح، ثم استخدم `render.yaml` بعد مراجعة تكلفة الخدمة والقرص.
6. بعد الاختبار الحي والتحقق من الديمومة، أنشئ أوقات الجدولة وفعّلها. الحد الأعلى 50 محاولة يوميًا لجميع المساعدين معًا.

## ما الذي لم يثبت بمجرد وجود الملفات؟

- صلاحية مفاتيحك الخاصة أو رصيد OpenAI وTavily أو الوصول للنموذج.
- نشر هذه النسخة على رابط عام أو إنشاء مستودع GitHub جديد.
- القدرة على إنجاز 50 تقريرًا مكتملًا كل يوم ضمن ميزانية ثابتة؛ تؤثر السرعة والتكلفة وتوافر الأخبار في ذلك.

تقارير الأخبار تستهدف 6 أخبار، وتكشف النقص عند عدم توافر الأدلة. الميزانية الافتراضية 5 دولارات يوميًا و100 دولار شهريًا لتقدير طلبات المزودين عبر التطبيق، ولا تشمل استضافة Render.

التفاصيل الكاملة في `DEPLOYMENT_AR.md` و`OPERATIONS_AR.md` و`security-model.md` داخل هذا المجلد. لا تحتاج إلى إرسال أي مفتاح API أو كلمة مرور في المحادثة.
