# AI HUB

إصدار المصدر: **1.4.3 — توسيع البحث الموحد وإظهار تغطية المصادر**. يوضح [سجل التحقق](docs/VALIDATION_AR.md) الفرق بين فحوص المصدر والنتائج الحية لكل إصدار.

منصة Python / FastAPI خاصة بمالك واحد لإدارة 13 مساعدًا، إعداد تقارير الأخبار، وحفظ النتائج والاستهلاك في قاعدة SQLite. اسم المشروع هو **AI HUB**، والمستودع الفعلي هو [aihub1971-code/AIHUB](https://github.com/aihub1971-code/AIHUB). خدمة Render القائمة اسمها `ai-hub`.

## ما الذي تتضمنه النسخة؟

- واجهة كاملة بالعربية والإنجليزية، مع اتجاه RTL/LTR، وتذكّر اختيار اللغة. تُنشأ التقارير الجديدة بلغة الواجهة، وتحتفظ التقارير القديمة بلغتها الأصلية.
- محادثة خاصة بالمالك للمساعدة في المنصة ومناقشة تقرير يختاره صراحة، مع حفظ المحادثات والرسائل على القرص الدائم. [دليل المحادثة واللغتين](docs/CHAT_AND_LANGUAGES.md).
- قائمة أخبار عمودية مريحة للقراءة: عنوان بارز، ملخص قصير، اسم الناشر وتاريخ النشر، وزر «فتح الخبر على الموقع الرسمي» في تبويب جديد. يظهر السياق السابق في قسم منفصل، وتُطوى ملاحظات المصادر وتفاصيل الاستخدام. يعرض قسم «المصادر في هذا التقرير» أعداد الأخبار المقبولة والسياق الإضافي لكل ناشر؛ تنبيه عدم إدراج مادة يصف هذه المحاولة فقط، ولا يثبت أن الناشر لم ينشر أخبارًا.
- تُقبل صفحة تغطية حية رسمية مباشرة ومؤرخة كبند واحد يحمل علامة «تغطية حية» / “Live coverage”. تبقى فحوص المصدر والتاريخ والصلة والتكرار؛ لا تُقبل الصفحة الرئيسية أو صفحة القسم أو فهرس البث العام.
- اتصال بـ OpenAI Responses API باستخدام `gpt-6.1-sol` افتراضيًا؛ البحث عبر أداة OpenAI المدمجة `web_search` والتوليد يستخدمان مفتاح `OPENAI_API_KEY` نفسه.
- تقارير الأخبار تعرض عدد البنود التي تدعمها الأدلة دون عدد إلزامي، ضمن حد معالجة أقصى قدره 20 بندًا للتقرير.
- البحث لجميع المساعدين الذين يستخدمونه محصور في Financial Times وThe Atlantic وPolitico وWall Street Journal وThe Daily Telegraph والجزيرة؛ [تفاصيل النطاقات والتغطية](docs/OPERATIONS_AR.md#3-البحث-والمصادر-المعتمدة).
- يبدأ كل تقرير إخباري باكتشاف موحد عبر النطاقات الثمانية معًا. بعد اكتماله، يمكن تنفيذ متابعة مستقلة واحدة لاستكمال الأدلة أو تنوع المصادر. تجمع متابعة التنوع نطاقات الناشرين غير الممثلين في مرشح واحد وطلب واحد، دون حصص لكل ناشر؛ أما استكمال الأدلة بعد استخلاص فارغ فيبقى على النطاقات الثمانية. تُدمج الأدلة في تقرير واحد، مع سقف طلبَي بحث Responses وطلب صياغة واحد. لا توجد مهام أو أبحاث متوازية حسب الناشر، ولا إعادة تلقائية لطلب HTTP فاشل. تبقى صلة إيران مستندة إلى عنوان المقال أو ملاحظاته المرتبطة به، ويُحسب التقرير حسب النشر أو التحديث مع فصل تاريخ الحدث.
- يستخدم البحث سياقًا مرتفعًا ووصولًا حيًا صريحًا، مع استعلام طبيعي موجز؛ لا تتضمن استعلامات أخبار اليوم تاريخًا تقويميًا أو سنة، وتبقى فترة النشر المطلوبة محفوظة لفحص النتائج بعد البحث. لغة البحث مستقلة عن لغة التقرير؛ يمكن لمتابعة بالإنجليزية استكمال بحث عربي أو تغطية مقتصرة على الجزيرة. إذا أخفقت المتابعة الاختيارية مع وجود أدلة أولية، تُحفظ تلك الأدلة ويُصاغ ما يدعمه الفاحص مع تنبيه بعدم اكتمال البحث والاحتفاظ بكامل الاحتياطي.
- يعالج استخراج الملاحظات العناوين الفرعية تحت عنوان عام، وحقل `Publication date`، والعنوان الصريح المكتوب كرابط Markdown. تُضبط خيارات الاقتباس والتاريخ من الملاحظات مع بقاء فحوص المصدر والنص والتوقيت. يُتعرف أيضًا على تاريخ صريح يتبعه وصف عربي يفيد أن ساعة النشر غير مذكورة، دون حذف ساعة أو منطقة زمنية موجودة أو استنتاج تاريخ مفقود. أُزيل تعارض تعليمات مساعد إيران القديمة بشأن عدد الأخبار واشتراط وقوع حدث جديد لكل مقال.
- سجل دائم للمحاولات والنتائج وتقدير التكلفة، مع حد عالمي أقصى قدره 50 محاولة تقرير في اليوم بحسب توقيت دبي.
- ميزانية افتراضية قدرها 5 دولارات يوميًا و100 دولار شهريًا مشتركة بين التقارير والمحادثة. رسائل المحادثة لا تستهلك حصة التقارير اليومية البالغة 50. هذه حدود تشغيل، وليست فاتورة أو ضمانًا لإنتاج 50 تقريرًا ضمنها.
- جدولة يومية داخل عملية التطبيق، متوقفة افتراضيًا حتى ضبط المفاتيح واختبار تقرير حقيقي.
- إعداد Render لخدمة Python واحدة وقرص دائم 1 GB، واختبارات GitHub Actions وحزمة تسليم نظيفة.

يحتاج البحث والتقارير والمحادثة إلى **مفتاح OpenAI API واحد** على الخادم، بالإضافة إلى اسم مستخدم وكلمة مرور لدخول المالك. الخدمة القائمة على Render تستخدم القرص الدائم نفسه. يتطلب إثبات جودة البحث فحص التقرير الفعلي ومصادره؛ `/health` وحده فحص لاستجابة الخدمة.

## ابدأ من هنا — Windows PowerShell

افتح PowerShell في جذر المستودع، حيث يقع `app/` بجانب `render.yaml`. عند استخراج حزمة مصدر حديثة يكون ذلك داخل مجلد `ai-hub`. استخدم Python 3.12:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
Copy-Item .env.example .env
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

ضع قيمة عشوائية طويلة في `APP_PASSWORD` داخل `.env`، واختر `APP_USERNAME`. أضف `OPENAI_API_KEY` بنفسك؛ يستخدمه البحث والتوليد معًا. لا ترسل المفاتيح في المحادثة ولا ترفع `.env` إلى GitHub. اترك `SCHEDULER_ENABLED=false` في البداية.

```powershell
python -m pytest
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

افتح [الواجهة المحلية](http://127.0.0.1:8000) وسجّل الدخول. تستخدم الواجهة `APP_USERNAME` و`APP_PASSWORD`؛ مفتاح OpenAI مخصص للخادم ولا يُدخل في شاشة تسجيل الدخول.

### macOS / Linux quickstart

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
cp .env.example .env
# Edit .env privately before continuing.
python -m pytest
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

Run the server from the repository root. The runtime dependencies are pinned in `requirements.txt`; test and deployment-validation tools are in `requirements-dev.txt`. SQLite and the scheduler use Python's standard library. The `.python-version` file keeps Render on the Python 3.12 release line.

لفحص الواجهة محليًا عند توفر Node.js، شغّل `node tests/test_ui_news.js` و`node tests/test_ui_chat.js`. تشمل فحوص الأخبار الواجهة الثنائية اللغة وتكامل المحادثة. تستخدم الفحوص بيانات اصطناعية ولا تتصل بالمزود. افتح تقريرًا إخباريًا محفوظًا لمراجعة العرض دون إعادة توليده؛ تبقى نسخة Markdown الأصلية للنسخ والتنزيل.

## التحقق من الاتصال

مع تشغيل التطبيق، افتح نافذة طرفية ثانية وفعّل البيئة الافتراضية فيها:

```bash
python scripts/smoke_test.py
```

الفحص الافتراضي يقرأ حالة الخدمة وقائمة المساعدين فقط. لإعداد **تقرير حي واحد** عبر مفتاح OpenAI بعد ضبطه، وهو طلب قد يترتب عليه استهلاك:

```bash
python scripts/smoke_test.py --live --agent iran-news
```

لفحص خدمة منشورة، مرّر رابطها الحقيقي إلى `--base-url`. اترك المصادقة داخل `.env` المحلي؛ لا تكتب كلمة المرور داخل الرابط أو أمر الطرفية. راجع سجل التقارير قبل إعادة طلب انتهت مهلته، لأن المزود قد يكون نفذه.
