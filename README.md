## الأخبار والأدلة

يستخدم المسار الجديد [OpenAI Responses مع البحث الحي](https://developers.openai.com/api/docs/guides/tools-web-search)، دون قائمة ناشرين ثابتة ودون NewsData. يكتشف مصادر دولية ومحلية وأولية بلغات مناسبة، ثم يفحص الخادم صفحات الناشرين التي ظهرت روابطها في مخرجات البحث الأصلية.

- نافذة الأخبار **12 ساعة بالضبط**، تُجمّد عند إنشاء المهمة، مع تخزين UTC وعرض توقيت دبي.
- قبول خبر يتطلب وقت نشر كاملًا مع منطقة زمنية من بيانات المقال أو عنصر نشر مربوط به. لا يُستبدل بوقت الزحف أو `dateModified` أو تاريخ يوم بلا ساعة.
- التغطية الحية تتطلب إدخالًا محددًا بوقت نشر مثبت داخل النافذة؛ تحديث الصفحة العام لا يكفي.
- الحد **20 تطورًا بعد التحقق والصلة وإزالة التكرار**، وليس أول 20 رابطًا خامًا ولا عددًا مطلوبًا ملؤه.
- عند غياب أدلة حديثة مؤهلة يظهر تقرير صريح بذلك. المراجع التاريخية والإبداعية موسومة بخلفية أو مراجع؛ العناصر القصصية الأصلية موسومة كتفسير إبداعي.

تُحفظ روابط المصادر ودليل وقت النشر وبصمات الصفحة وبيانات الاستشهاد. يثبت ذلك ما نُشر وتوقيته؛ صحة الادعاءات والتقدير التحليلي أمران منفصلان يوضحهما التقرير. لا يضمن البحث تغطية كل بلد أو ناشر.

يعالج تصحيح 2.0.1 ملاحظات التشغيل الأول: اختصار التقرير الخالي، وإزالة عنوان القسم المكرر، واستبعاد صفحات التحقق الآلي وتنظيف عناوين المراجع، ومواءمة إسناد المحتوى الإبداعي مع عقد التقرير. اكتملت سبعة تقارير عربية من ثماني محاولات أولية؛ أخفق Moodboard في عقد الصياغة. هذه نتيجة الإصدار الأساسي، وتحتاج إصلاحات التصحيح إلى تحقق حي مستقل.

## الحفظ وPDF والمحادثة

المهام محفوظة في SQLite وتعرض مراحل فعلية: البحث، فحص المصادر، التحليل، إعداد PDF، ثم الجاهزية. آخر تقرير ناجح يبقى متاحًا أثناء إنشاء تقرير جديد. لكل نسخة معرّف ونافذة بحث ثابتان؛ إعادة فتحها أو تنزيلها لا تعيد البحث.

يُنشأ PDF محليًا من البيانات نفسها التي تعرضها الواجهة، مع نص عربي وإنجليزي قابل للتحديد ومراجع قابلة للنقر وتسلسل زمني أو لوحة إبداعية بحسب نوع التقرير. يستخدم [fpdf2 وتشكيل النص](https://py-pdf.github.io/fpdf2/TextShaping.html) وخطوط Noto المرفقة بترخيص SIL OFL 1.1 في `app/assets/fonts/`؛ مصادر الخطوط وبصماتها محفوظة في `SOURCES.json`.

المحادثة داخل مساحة المساعد ترتبط بالتقرير المعروض، والمحادثة العامة تستطيع الاستفادة من تقارير الجلسة المحفوظة. السؤال الذي يحتاج معلومات أحدث يمكن أن ينشئ مهمة بحث جديدة واضحة الحالة؛ التقرير القديم لا يُعاد كتابته. تغيير لغة الواجهة لا يُنشئ تقريرًا جديدًا تلقائيًا، وتبقى لغة كل نسخة محفوظة معلومة.

## الدخول والتوافق

`/` مساحة عامة بلا اسم مستخدم أو كلمة مرور، مع جلسة متصفح معزولة. `/admin` لوحة المالك المحمية. لا تعرض الاستجابات العامة المفاتيح أو التكلفة أو مسارات التخزين، ولا تمنح الزائر تقارير الإدارة أو جلسة أخرى. السجل مرتبط بملف تعريف الارتباط؛ حذفه لا يحول الجلسة إلى حساب قابل للاستعادة بكلمة مرور.

تبقى بعض واجهات 1.x ووحدة NewsData للتوافق مع الإدارة والأرشيف السابق. **الواجهة الجديدة تستخدم `/v1/public/workspace/*` و`app/research.py`، ولا تستخدم مسار NewsData القديم أو سياسة الناشرين الستة أو حد النتائج الخام السابق.**

## التشغيل المحلي

Python 3.12، من جذر المستودع:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
cp .env.example .env
```

في PowerShell استخدم `py -3.12 -m venv .venv` ثم `.\.venv\Scripts\Activate.ps1` و`Copy-Item .env.example .env`. ضع `OPENAI_API_KEY` وبيانات المالك داخل `.env` محليًا فقط. لا تحتاج الواجهة الجديدة إلى `NEWSDATA_API_KEY`.

```bash
python -m pytest
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

افتح [المساحة المحلية](http://127.0.0.1:8000). الاختبارات تستخدم مزودين وصفحات اصطناعية، ولا تثبت وحدها جودة الأخبار الحية. أوامر smoke القديمة تختبر API القديم؛ ليست معيار تحقق مساحة 2.0.

## API الجديدة

ابدأ بـ`GET /v1/public/bootstrap` لإنشاء جلسة. كل المسارات التالية تخص الجلسة نفسها:

| الطريقة والمسار | الغرض |
|---|---|
| `GET /v1/public/workspace/config` | المساعدون والعروض واللغات |
| `POST /v1/public/workspace/agents/{id}/reports` | مهمة جديدة؛ `{topic, language}` مع `Idempotency-Key` |
| `GET /v1/public/workspace/agents/{id}` | آخر نسخة ناجحة والمهمة الجارية |
| `GET /v1/public/workspace/jobs/{id}` | التقدم والتقرير عندما يُحفظ |
| `GET /v1/public/workspace/reports` | نسخ الجلسة المحفوظة |
| `GET /v1/public/workspace/reports/{id}` | نسخة منظمة ثابتة |
| `GET /v1/public/workspace/reports/{id}/pdf` | تنزيل PDF الجاهز |
| `POST /v1/public/workspace/reports/{id}/pdf/retry` | إعادة إخراج PDF دون بحث جديد |
| `POST /v1/public/workspace/chat/conversations/{id}/messages` | سؤال متصل بالتقارير والبحث عند الحاجة |

تُنشأ المحادثات وتُقرأ عبر `/v1/public/chat/conversations` الحالية. لا يرسل العميل تاريخ محادثة نظاميًّا أو مفاتيح أو أوقات نشر موثوقة.
