# AI HUB

إصدار المصدر: **1.5.1 — واجهة عامة ولوحة إدارة خاصة، وأول 20 نتيجة لأخبار حرب إيران**. راجع [سجل التحقق](docs/VALIDATION_AR.md) لحالة الاختبارات والنشر الفعلية.

منصة Python / FastAPI بواجهة عامة ولوحة إدارة لمالك واحد، تضم 13 مساعدًا ومحادثة عربية وإنجليزية، وتحفظ التقارير والمواعيد والاستهلاك في SQLite. المستودع الفعلي [aihub1971-code/AIHUB](https://github.com/aihub1971-code/AIHUB)، والخدمة القائمة [ai-hub-vc8w.onrender.com](https://ai-hub-vc8w.onrender.com).

## أخبار حرب إيران

مساعد **أخبار حرب إيران** (`iran-news`) يجلب المقالات الإنجليزية مباشرة من NewsData.io بالبحث الثابت `iran war`، أي وجود الكلمتين بصيغة AND. يستخدم نافذة آخر 48 ساعة، ويعرض عنوان المقال ووصفه المتاح واسم ناشره وتاريخ نشره وزرًا يفتح المقال الأصلي. لا تسري عليه قائمة الناشرين الستة السابقة؛ يعرض المصادر الفعلية التي يعيدها NewsData وتقبلها فحوص الرابط والبيانات والتوقيت.

يقتصر كل بحث على **أول 20 نتيجة يعيدها المزود قبل فحوص القبول**؛ قد يظهر عدد أقل بعد استبعاد غير الصالح أو المكرر. حجم الصفحة الافتراضي 10، ويتوقف **التالي** عند بلوغ هذا الحد أو انتهاء النتائج. **السابق** والصفحات المجلوبة سابقًا يُقرآن من التخزين دون طلب مزود جديد. كل تشغيل يجلب صفحة واحدة؛ الصفحة الجديدة محاولة تقرير ورصيد مستقل، وتبقى مؤشرات المزود داخل الخادم. يقبل إعداد الحجم 1–50، لكن الطلب الفعلي لا يتجاوز المتبقي من حد 20 ولا حدود خطة المزود.

عند جلب كل صفحة، يحاول OpenAI ترجمة العناوين والأوصاف إلى العربية في دفعات لا تتجاوز خمسة مقالات، حتى عند اختيار الواجهة الإنجليزية. تُحفظ الإنجليزية والترجمة، لذلك يعمل تبديل اللغة فورًا دون طلب جديد. إذا غابت الترجمة أو فشلت، يبقى الخبر الإنجليزي مع توضيح حالته. لا يُنشأ ملخص بمعلومات إضافية عندما لا يرسل المزود وصفًا.

**الخطة المجانية لـNewsData تؤخر الأخبار 12 ساعة**، وتسمح حتى 10 مقالات لكل صفحة؛ لذلك قد تكون أحدث النتائج أقدم مما تتوقع. لا تُستخدم معاملات الأرشيف أو `timeframe` المدفوعة. كتابة تاريخ آخر في المهمة لا تحول هذا المساعد إلى بحث أرشيفي؛ يظهر نطاق التغطية الفعلي في التقرير. [تفاصيل الخدمة الرسمية](https://newsdata.io/openapi.json) و[حدود الخطة](https://newsdata.io/blog/pricing-plan-in-newsdata-io/).

## الواجهة العامة والإدارة

الواجهة العامة عند `/` متاحة دون تسجيل دخول، وتضم 13 مساعدًا والمحادثة بالعربية والإنجليزية؛ يرسل Enter البحث. لا تعرض التكاليف أو السجلات الإدارية. تبقى لوحة المالك عند `/admin`، وتبقى مسارات `/v1/*` الإدارية خلف مصادقة المالك، باستثناء المسارات العامة المستقلة تحت `/v1/public/*`. لا يتطلب هذا الفصل مفاتيح أو إعدادات خدمة جديدة.

تقارير الزائر ومحادثاته تخص جلسة متصفحه، وتبقى منفصلة عن أرشيف المالك. تستخدم الواجهة العامة `/v1/public/*`؛ لا تحتاج إلى مشاركة بيانات دخول الإدارة.

## بقية المنصة

- بقية المساعدين والمحادثة تستخدم OpenAI Responses API، والنموذج الافتراضي `gpt-6.1-sol`. مساعدو البحث الآخرون يحتفظون بسياسة المصادر وحدودهم الحالية؛ [دليل التشغيل](docs/OPERATIONS_AR.md).
- واجهة عربية وإنجليزية واتجاه RTL/LTR، مع محادثات محفوظة وإرفاق تقرير تختاره صراحة. المحادثة تشرح المنصة والتقارير، ولا تشغّل البحث أو الإعدادات بنفسها. [دليل المحادثة واللغتين](docs/CHAT_AND_LANGUAGES.md).
- حد مشترك أقصى **50 محاولة تقرير يوميًا بتوقيت دبي**، وميزانية OpenAI قدرها **5 دولارات يوميًا و100 دولار شهريًا** للتقارير والمحادثة والترجمة معًا. رسائل المحادثة لا تستهلك حصة التقارير.
- رصيد NewsData منفصل عن الدولار: صفحة latest واحدة تستهلك رصيدًا واحدًا، والحد المحلي الافتراضي **200 رصيد يوميًا**. لا يحوّل التطبيق الاشتراك إلى تكلفة دولار مفترضة. هذه حدود تشغيل وليست ضمانًا لإنتاج العدد الأقصى من التقارير.
- جدولة متوقفة افتراضيًا، وخدمة Render واحدة مع عامل Uvicorn واحد وقرص دائم 1 GB. البناء من ملفات `app/` مباشرة، دون استخراج ZIP.

## ابدأ من هنا — Windows PowerShell

افتح PowerShell في جذر المستودع، حيث يقع `app/` بجانب `render.yaml`. عند استخراج حزمة مصدر حديثة يكون ذلك داخل مجلد `ai-hub`. استخدم Python 3.12:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
Copy-Item .env.example .env
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

ضع قيمة عشوائية طويلة في `APP_PASSWORD` داخل `.env`، واختر `APP_USERNAME`. أضف `NEWSDATA_API_KEY` لأخبار حرب إيران و`OPENAI_API_KEY` للترجمة العربية وبقية المساعدين والمحادثة. لا ترسل المفاتيح في المحادثة ولا ترفع `.env` إلى GitHub. اترك `SCHEDULER_ENABLED=false` في البداية.

```powershell
python -m pytest
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

افتح [الواجهة المحلية العامة](http://127.0.0.1:8000) للاستخدام دون تسجيل دخول. افتح [لوحة الإدارة](http://127.0.0.1:8000/admin) وسجّل الدخول بـ`APP_USERNAME` و`APP_PASSWORD` للوصول إلى الأرشيف الإداري والتكاليف والجداول؛ مفتاحا المزودين مخصصان للخادم.

### macOS / Linux quickstart

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
cp .env.example .env
# Edit .env privately before continuing.
python -m pytest
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

Open `/` for the public Arabic/English interface, or `/admin` for owner sign-in and administration. Public responses omit accounting data. Run the server from the repository root. The runtime dependencies are pinned in `requirements.txt`; test and deployment-validation tools are in `requirements-dev.txt`. SQLite and the scheduler use Python's standard library. The `.python-version` file keeps Render on the Python 3.12 release line.

لفحص الواجهة محليًا عند توفر Node.js، شغّل `node tests/test_ui_news.js` و`node tests/test_ui_chat.js`. تشمل فحوص الأخبار الواجهة الثنائية اللغة وتكامل المحادثة. تستخدم الفحوص بيانات اصطناعية ولا تتصل بالمزود. افتح تقريرًا إخباريًا محفوظًا لمراجعة العرض دون إعادة توليده؛ تُحفظ نسختا أخبار NewsData العربية والإنجليزية للعرض والنسخ والتنزيل؛ التقارير القديمة تبقى محفوظة كما أُنشئت.

## التحقق من الاتصال

مع تشغيل التطبيق، افتح نافذة طرفية ثانية وفعّل البيئة الافتراضية فيها:

```bash
python scripts/smoke_test.py
```

الفحص الافتراضي يقرأ حالة الخدمة وقائمة المساعدين فقط. لجلب **صفحة حية واحدة** من أخبار حرب إيران بعد ضبط المفتاح، مع استهلاك رصيد NewsData وتكلفة الترجمة العربية عند تهيئتها:

```bash
python scripts/smoke_test.py --live --agent iran-news
```

لفحص خدمة منشورة، مرّر رابطها الحقيقي إلى `--base-url`. اترك المصادقة داخل `.env` المحلي؛ لا تكتب كلمة المرور داخل الرابط أو أمر الطرفية. راجع سجل التقارير قبل إعادة طلب انتهت مهلته، لأن المزود قد يكون نفذه.
