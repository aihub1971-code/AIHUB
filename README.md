## الأخبار والأدلة

تستخدم المجالات الإخبارية السبعة خدمة `app/news_feed.py` لجلب NewsData بالعربية والإنجليزية. يبقى التاريخ وStory Moodboard على مسار البحث الأصلي عبر OpenAI وفحص المراجع. لا يستخدم مسار الأخبار الجديد قائمة الناشرين القديمة أو سياسة API السابقة ذات الـ 48 ساعة.

- نافذة الأخبار **12 ساعة بالضبط**، مع UTC في التخزين وتوقيت دبي في العرض. تُجمّد نافذة التقرير، وتستبعد الواجهة من القائمة الحية المقالات التي تجاوز عمرها 12 ساعة.
- الحد **100 خبر مقبول بعد فحص التوقيت والصلة وإزالة التكرار**. هذا سقف، ولا يُملأ بأخبار أقدم عند قلة النتائج.
- أساس التوقيت بيانات NewsData المنظمة `pubDate` و`pubDateTZ`. مستوى الدليل `provider_metadata_only`؛ لا يثبت فحص نص صفحة الناشر ولا صحة الادعاءات المنقولة.
- الجلب محدود بـ**20 صفحة أو 90 ثانية**، ويتوقف مبكرًا عند بلوغ العدد أو نهاية المصدر أو استنفاد النافذة. حجم الصفحة حتى **10** عند عدم معرفة الخطة أو تهيئتها مجانية، وحتى **50** عند تهيئتها مدفوعة؛ التهيئة لا تثبت استحقاق الحساب.
- مخزن الأخبار مشترك بين جلسات الزوار، مع فاصل تحديث **15 دقيقة** وحجز تنفيذ واحد للمزود. تمنع فترات التهدئة المشتركة تكرار طلبات المصدر المتعثر؛ التحديث اليدوي لا يتجاوزها. سقف NewsData الحالي **200 رصيد يوميًا**، مشترك مع الاستخدام السابق.

تظهر حالات محدّثة ومحفوظة وجارٍ التحديث وفارغة وخطأ مزود بوضوح، مع آخر تحديث ناجح والعدد الفعلي وروابط المصادر. يبدأ GET تحديثًا خلفيًا عند حلول موعده، ويطلب زر التحديث العملية المقيدة نفسها. **تحديث لوحة الأخبار لا يستدعي نموذجًا أو ينشئ تقريرًا.** التحليل والترجمة طلبات بلا أدوات، محدودة ومحجوزة الميزانية ضمن إنشاء تقرير صريح؛ تعرض الواجهة لغة المصدر عند غياب ترجمة محفوظة.

في الفحص التشخيصي بتاريخ **20 أكتوبر 2026، 18:11:09 UTC** كان أحدث خبر أعاده المصدر منشورًا عند **06:10:59 UTC**؛ كانت أخبار الصفحة العشرة خارج نافذة 12 ساعة، فكان العدد المؤهل صفرًا. رفض المزود حجم الصفحة 50 وقال إن النطاق المتاح 1–10. هذه ملاحظات عن الوصول الحالي، ولا تثبت نوع الخطة. تظهر إمكانية تأخر المصدر بدل تقديم خبر قديم باعتباره حديثًا؛ لم يُثبت بعد أن الإصدار الجديد نجح حيًا. نتائج 2.0.1–2.0.3 السابقة محفوظة في ملاحظاتها وسجل التحقق.

## الحفظ وPDF والمحادثة

المهام محفوظة في SQLite وتعرض مراحل فعلية: البحث، فحص المصادر، التحليل، **الحفظ**، إعداد PDF، ثم الجاهزية. يُحفظ سبب الفشل الآمن ومرجعه ومرحلته، وتستعيد إعادة تحميل الصفحة آخر حالة. يبقى آخر تقرير ناجح متاحًا أثناء التعثر، وإعادة المحاولة الصريحة تحترم مهلة الانتظار. لكل نسخة معرّف ونافذة ثابتان؛ إعادة فتحها أو تنزيلها لا تعيد البحث.

يُنشأ PDF محليًا من البيانات نفسها التي تعرضها الواجهة، مع نص عربي وإنجليزي قابل للتحديد ومراجع قابلة للنقر وتسلسل زمني أو لوحة إبداعية بحسب نوع التقرير. يستخدم [fpdf2 وتشكيل النص](https://py-pdf.github.io/fpdf2/TextShaping.html) وخطوط Noto المرفقة بترخيص SIL OFL 1.1 في `app/assets/fonts/`؛ مصادر الخطوط وبصماتها محفوظة في `SOURCES.json`.

المحادثة داخل مساحة المساعد ترتبط بالتقرير المعروض، والمحادثة العامة تستطيع الاستفادة من تقارير الجلسة المحفوظة. السؤال الذي يحتاج معلومات أحدث يمكن أن ينشئ مهمة بحث جديدة واضحة الحالة؛ التقرير القديم لا يُعاد كتابته. تغيير لغة الواجهة لا يُنشئ تقريرًا جديدًا تلقائيًا، وتبقى لغة كل نسخة محفوظة معلومة.

## الدخول والتوافق

`/` مساحة عامة بلا اسم مستخدم أو كلمة مرور، مع جلسة متصفح معزولة. `/admin` لوحة المالك المحمية. لا تعرض الاستجابات العامة المفاتيح أو التكلفة أو مسارات التخزين، ولا تمنح الزائر تقارير الإدارة أو جلسة أخرى. السجل مرتبط بملف تعريف الارتباط؛ حذفه لا يحول الجلسة إلى حساب قابل للاستعادة بكلمة مرور.

تبقى بعض واجهات 1.x ومحول NewsData القديم للتوافق مع الإدارة والأرشيف السابق. **المساحة الحالية تستخدم `/v1/public/workspace/*` ومخزن `app/news_feed.py` الجديد**؛ لا تحوّل طلباتها إلى API الأرشيف القديم أو حدوده السابقة.

## التشغيل المحلي

Python 3.12، من جذر المستودع:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
cp .env.example .env
```

في PowerShell استخدم `py -3.12 -m venv .venv` ثم `.\.venv\Scripts\Activate.ps1` و`Copy-Item .env.example .env`. ضع `NEWSDATA_API_KEY` للأخبار، و`OPENAI_API_KEY` للتحليل والترجمة والتاريخ والإبداع والمحادثة، وبيانات المالك داخل `.env` محليًا فقط. لا تستنتج خطة NewsData من وجود المفتاح.

```bash
python -m pytest
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

افتح [المساحة المحلية](http://127.0.0.1:8000). الاختبارات تستخدم مزودين وصفحات اصطناعية، ولا تثبت وحدها جودة الأخبار الحية. أوامر smoke القديمة تختبر API القديم؛ ليست معيار تحقق مساحة 2.0.

هذه **سقوف حماية وليست فواتير متوقعة**، ولا يرفعها 2.0.4. يُحجز تقدير محافظ للتحليل والترجمة أو البحث الأصلي قبل العمل المدفوع؛ يُسوّى عند اكتمال بيانات الاستخدام ويُحتفظ به عند الغموض. تبقى أفعال البحث الأصلي محدودة للتاريخ والإبداع، ولا تُستخدم لتحويل تحديث الأخبار إلى بحث نموذجي غير محدود. لا إعادة محاولات نموذج مدفوعة تلقائية. راجع [التشغيل والحساب](docs/OPERATIONS_AR.md).

## API الجديدة

ابدأ بـ`GET /v1/public/bootstrap` لإنشاء جلسة. كل المسارات التالية تخص الجلسة نفسها:

| الطريقة والمسار | الغرض |
|---|---|
| `GET /v1/public/workspace/config` | المساعدون والعروض واللغات |
| `GET /v1/public/workspace/agents/{id}/news?language=ar` | مخزن أخبار المجال؛ يبدأ تحديثًا خلفيًا عند استحقاقه |
| `POST /v1/public/workspace/agents/{id}/news/refresh` | `{language}`؛ طلب تحديث يخضع للفاصل والرصيد نفسيهما |
| `POST /v1/public/workspace/agents/{id}/reports` | مهمة جديدة؛ `{topic, language}` مع `Idempotency-Key` |
| `GET /v1/public/workspace/agents/{id}` | آخر نسخة ناجحة والمهمة الجارية وآخر مهمة بما فيها الفشل |
| `GET /v1/public/workspace/jobs/{id}` | التقدم والتقرير عندما يُحفظ |
| `GET /v1/public/workspace/reports` | نسخ الجلسة المحفوظة |
| `GET /v1/public/workspace/reports/{id}` | نسخة منظمة ثابتة |
| `GET /v1/public/workspace/reports/{id}/pdf` | تنزيل PDF الجاهز |
| `POST /v1/public/workspace/reports/{id}/pdf/retry` | إعادة إخراج PDF دون بحث جديد |
| `POST /v1/public/workspace/chat/conversations/{id}/messages` | سؤال متصل بالتقارير والبحث عند الحاجة |

تُنشأ المحادثات وتُقرأ عبر `/v1/public/chat/conversations` الحالية. لا يرسل العميل تاريخ محادثة نظاميًّا أو مفاتيح أو أوقات نشر موثوقة.

## ملفات التطوير والتسليم

`agent_profiles.py` يحدد التخصصات، و`news_feed.py` يدير الأخبار والمخزن والرصيد، و`research.py` يوجّه مسار التقرير، و`report_jobs.py` يدير التنفيذ، و`report_store.py` يحفظ النسخ، و`report_pdf.py` يخرج PDF. تغييرات قاعدة البيانات إضافية وتحافظ على الأرشيف القائم. يميز التقرير العدد المجموع `actual_article_count` والعدد المحلل `analyzed_article_count` والسقف المطلوب؛ وجود 100 مقال في المخزن لا يعني تحليلها جميعًا بالتفصيل.
