# AI HUB — مساحات الوكلاء

واجهة عربية وإنجليزية للبحث والمحادثة والتقارير المؤرخة. تعرض الصفحة الرئيسية **بطاقات سبعة وكلاء فقط**. فتح بطاقة أو تبديل الوكيل يستعيد المحادثة والبيانات المحفوظة؛ لا يبدأ بحثًا أو تقريرًا أو تحديث أخبار. يبدأ العمل الجديد عندما ترسل سؤالًا أو تختار **تحديث الأخبار** أو **إنشاء تقرير حديث** داخل مساحة الوكيل.

تصف هذه الوثيقة مصدر **2.1.6**. لا تثبت نشره أو نجاحه على الخدمة الحية؛ تُضاف أدلة الاختبارات والنشر والفحص الفعلي إلى [سجل التحقق](docs/VALIDATION_AR.md). راجع [دليل الترقية](docs/UPGRADE_2_1.md)، و[دليل الطلبات اليدوية](docs/MANUAL_REQUESTS_2_1_1.md)، و[تصحيح التقارير الخلفية](docs/BACKGROUND_REPORTS_2_1_2.md)، و[بحث الويب داخل المحادثة](docs/OPEN_WEB_CHAT_2_1_6.md)، و[سجل إصلاحات الاستشهادات السابقة](docs/CHAT_RESEARCH_2_1_3.md). المستودع: [aihub1971-code/AIHUB](https://github.com/aihub1971-code/AIHUB).

## الوكلاء النشطون

| الوكيل | مجال العمل |
|---|---|
| الدخل الأساسي الشامل | البرامج والتقييمات والتمويل والآثار الاجتماعية والاقتصادية |
| أخبار إيران | إيران والولايات المتحدة والتداعيات الإقليمية، بما فيها الإمارات |
| التجارة بين الإمارات والاتحاد الأوروبي | المفاوضات والأسواق والتنظيم والاستثمار |
| الإحاطة الجيوسياسية | الصراعات والدبلوماسية والتحولات الدولية |
| مرصد التعليم | نتائج التعلم والمهارات والسياسات والتقنيات التعليمية |
| رفيق القراءة التاريخية | الكتب والسياق التاريخي والمصادر والقراءات المقارنة |
| الإحاطة الاقتصادية والثقافية | الاقتصاد والثقافة والسياحة والاقتصاد الإبداعي |

يتاح لكل وكيل مسارا **NewsData وبحث الويب** بحسب حاجته إلى الأدلة. أزيل Story Moodboard وDecision Briefing Partner من التسجيل والتنفيذ النشطين، إضافة إلى الوكلاء الأربعة المتوقفين سابقًا. تبقى الأصول الأصلية والأرشيف المحفوظ؛ وجود ملف مهارة أو تقرير قديم لا يعيد تفعيل وكيل.

## كيف تعمل المساحة؟

لكل زائر محادثة دائمة مستقلة مع كل وكيل، تستعاد من الخادم عند العودة. يمكن للوكيل الاستفادة من السياق ذي الصلة والتقارير المحفوظة والملاحظات المعتمدة داخل مساحة الزائر نفسه. في **المعرفة المشتركة** يمكنك اقتراح تفضيل أو تصحيح أو معلومة، ثم اعتمادها أو رفضها. اعتماد الملاحظة يعبر عن قرارك؛ لا يحولها إلى دليل منشور موثق ولا يدرّب النموذج.

يمكن لكل وكيل البحث في المصادر المتاحة على الويب للإجابة عن سؤالك، دون التقيد بمراجع التقارير المحفوظة. تساعد التقارير والذاكرة على فهم السياق. لا تنطبق نافذة الأخبار البالغة 12 ساعة على الأسئلة التاريخية أو البحث العام؛ تبقى تواريخ الأدلة وحدودها واضحة. إذا طلبت الاقتصار على تقرير أو عدم إجراء بحث، يحترم الوكيل ذلك.

تظهر مراحل البحث وفحص المصادر، ثم تصل الإجابة أثناء وصول النص الفعلي من المزود. النص الجزئي يبقى نصًا عاديًا حتى اكتمال الإجابة وفحص روابطها؛ عندها يعرض Markdown وروابط المصادر الآمنة. السؤال العادي يلقى إجابة داخل المحادثة؛ لا يُنشأ تقرير وPDF إلا عند طلب ذلك صراحة. لا توجد وجهة منفصلة باسم AI HUB Chat.

في **الأخبار والتقارير** يظهر المخزن المحفوظ أولًا. زر تحديث الأخبار يطلب جلبًا صريحًا، وزر إنشاء تقرير حديث يفتح ملف الإحاطة ويعرض مراحل العمل. التقرير وPDF نسختان مؤرختان؛ لا يعيد فتحهما البحث. الأوقات المعروضة بتوقيت دبي، وتغيير اللغة لا يعيد توليد التقرير أو ترجمته تلقائيًا.

## التحديث اليدوي والأدلة

- سقف NewsData هو **50 نتيجة خام عبر الصفحات قبل فحص التوقيت والصلة وإزالة التكرار**. ليست هناك محاولة لجلب 50 خبرًا مقبولًا مهما بلغ عدد النتائج الخام.
- نافذة الأخبار الحالية **آخر 12 ساعة**. قد يكون عدد الأخبار المؤهلة أقل أو صفرًا. لا تُدرج مادة أقدم لملء العدد.
- قراءة `GET` أو فتح الصفحة أو تبديل اللغة لا تستدعي مزود أخبار أو نموذجًا. قد تستمر قراءة حالة تحديث طلبته بالفعل، دون بدء تحديث آخر.
- عند قصور NewsData أو تعذره، يمكن للعمل الصريح استخدام بحث ويب إضافي محدود. **قد يستهلك هذا البحث استخدام OpenAI وحصة التطبيق**؛ لا يصح وصف كل تحديث يدوي بأنه بلا استدعاء نموذج.
- بيانات NewsData الوصفية تبقى منفصلة عن نصوص صفحات الناشرين المفحوصة. تظهر حدود الأدلة والتواريخ وروابط المصادر. يمكن أن ينتج التقرير تحليلًا قائمًا على خلفية مؤرخة مع تنبيه واضح عند عدم العثور على تطور حديث.

المخزن الإخباري العام مشترك، أما محادثات الزائر وتقاريره وملاحظاته فخاصة بمساحته. الطلب اليدوي الجديد لا ينتظر فاصل المخزن البالغ 15 دقيقة؛ تبقى مهلة المزود الحقيقية وحماية الطلبات الجارية ساريتين. تنتظر الطلبات المقبولة دورها عند انشغال الخدمة، دون بدء أبحاث تلقائية. تبقى الجدولة معطلة عبر `SCHEDULER_ENABLED=false`. التفاصيل في [التشغيل](docs/OPERATIONS_AR.md) و[نموذج الأمان](docs/security-model.md).

## المسارات

| الواجهة | الاستخدام |
|---|---|
| `/` | مساحات الزائر دون بيانات المالك |
| `/admin/agents` | واجهة الوكلاء نفسها للمالك، محمية بالمصادقة |
| `/admin` | لوحة الصيانة والأرشيف والإعدادات التشغيلية السابقة |
| `/v1/public/workspace/*` | API مساحة الزائر، محكومة بجلسة المتصفح |
| `/v1/workspace/*` | API مساحة المالك، محمية بمصادقة المالك |

لا تنقل الواجهة الجديدة بيانات Basic من لوحة الصيانة ولا تحفظها في JavaScript أو تخزين المتصفح. يعالج المتصفح مصادقة المالك. ملكية السجلات يفرضها الخادم، بما فيها PDF والمعرفة المشتركة.

## التشغيل المحلي

من جذر المستودع، باستخدام Python 3.12:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
cp .env.example .env
```

في PowerShell استخدم `py -3.12 -m venv .venv` ثم `.\.venv\Scripts\Activate.ps1` و`Copy-Item .env.example .env`. ضع مفاتيح المزود وبيانات المالك في البيئة الخاصة فقط. ثم شغّل:

```bash
python -m pytest
node tests/test_ui_workspace.js
node tests/test_ui_news.js
node tests/test_ui_public.js
node tests/test_ui_chat.js
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

افتح [المساحة المحلية](http://127.0.0.1:8000). الاختبارات المحلية تستخدم بيانات ومزودين اصطناعيين؛ نتائجها لا تثبت وصول الخدمة الحية إلى الأخبار أو حساب المزود.
